## Promise (buyer-facing)

**Phobia** is a full-viewport (or mid-page) **cursor-fleeing forms** section. On a pure black void, photo cutouts and letter debris rest in a crafted cluster. When the pointer is away, they **spread**. When the pointer approaches, they **flee radially** from their homes with rotation and scale, then **elastic return** when clear. A premium white-glow cursor with a soft trail makes the interaction feel expensive, not gimmicky.

**Why use it:**
- Your brand objects become alive without a 3D pipeline
- Pointer ownership feels intimate and memorable on agency and campaign pages
- Every cutout, letter, rest pose, and influence radius is meant to be yours
- One self-contained section with no required site chrome

**How you build it:** download the product pack (prompt + source + cutouts). Tell your AI: *Build Phobia using the files in this folder. Read PROMPT.md.*

## Design System

**Aesthetic Direction:** pure black void, photo cutouts, white letter debris, crystalline white cursor bloom. No UI chrome required.

**Craft direction:** gallery installation x playful editorial x high-end digital toy. Calm when idle, electric when approached.

**Do not:**
- Use Club GSAP InertiaPlugin (vanilla GSAP tweens only)
- Measure flee distance from the live offset position (must use **rest center**)
- Ship olive or system default cursors as the signature
- Burn MS storefront chrome into the section
- Require scroll pin for the core interaction (this is pointer-first)

**Differentiation:**

| vs | Phobia must not become |
|----|------------------------|
| Helix | Scroll-pinned WebGL helix gallery |
| Studio Sequence | Scroll camera pull-out with film |
| Actually! / Lineup | 3D product vessel + pin |
| Generic hover float | Uniform CSS hover without rest-based radial flee |

## Layout Structure

- **Section only** - full viewport height (`h-dvh`), black background, overflow hidden
- **Stage** centered layer (~1872×1056 max) holding absolute rest poses
- **Objects** = images + optional letter spans; GSAP `x`/`y` are offsets from rest
- **Cursor** + trail as HTML overlays (custom, not OS cursor)
- No forced header or footer

## Motion Specification

**Mode:** pointer-reactive (not scroll-scrub, not free-play film).

| Event | Feel |
|-------|------|
| No pointer in section | Treat pointer as viewport **center** → objects **spread** |
| Pointer enters / moves | Real coords; far from rest → settle home; near rest → radial flee |
| Clear of influence | Elastic return to x:0 y:0, base rotation, scale 1 |
| Reduced motion | No flee tweens |

**Desktop params:** influenceRadius **460**, maxDistance **380**, rotForce **30**, scaleForce **0.2**, flee ease `power4.out` 0.45s, return `elastic.out(1, 0.35)` 1.2s.  
**Mobile (≤767):** 260 / 110 / 12 / 0.1.

**Math (non-negotiable):** distance and angle use **rest center** = visual center minus current GSAP offset. Flee: `L = ((R-d)/R)^1.6`, `U = L * maxDistance`, offset `(-cosθ·U, -sinθ·U)`.

## Responsive Behavior

- Desktop: full influence, custom cursor hidden OS cursor
- Tablet / phone: softer params; touch still drives flee via pointer events
- Reduced motion: static rest composition
- Ultrawide: stage capped so cluster stays intentional

## Accessibility

- Section `aria-label` describing decorative interactive forms
- Images decorative (`alt=""`) unless buyer supplies meaningful alts
- Respect `prefers-reduced-motion`
- Do not trap keyboard focus; interaction is pointer-optional

## Performance Notes

- GSAP transforms only (`x`, `y`, `rotation`, `scale`, `force3D`)
- `overwrite: "auto"` on tweens to avoid pile-up
- Optimize cutouts (WebP preferred); avoid huge unoptimized PNGs
- No Three.js required
