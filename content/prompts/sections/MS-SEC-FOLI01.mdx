## Design System

**Aesthetic Direction:** **FOLIO** - mid-page scroll-pivot liquid glass **decision section** (not a full-bleed hero, not Prism multi-panel constellation). Dark translucent enterprise cards over a looping abstract motion film. Five dense board-ready sheets. One-way paper journey on `rotateX`. Syne display + DM Sans. Cool white type on glass. Soft iridescent rim (cyan / violet / rose).

**Famous-UI craft direction (not a clone):** Linear / Stripe enterprise density × Apple Liquid Glass material discipline (fill + specular + edge only) × private-bank presentation pacing. Serious. Dense. Readable.

**Typography:**
- Display / H2: Syne 600, tracking `-0.03em`, `clamp(1.55rem, 3.1vw, 2.35rem)`
- Sheet titles: Syne 600, `clamp(1.3rem, 2.3vw, 1.75rem)`
- Body / lead: DM Sans 400, 13-15px, line-height 1.55
- Labels / chips: 9-11px uppercase tracking `0.1-0.22em`
- Metrics: Syne 700, tabular nums

**Color tokens:**
| Token | Value |
|-------|--------|
| Stage veil | `rgba(8,10,16,0.2-0.5)` over film |
| Glass fill | `rgba(255,255,255,0.08-0.18)` |
| Ink on glass | `#FFFFFF` + soft shadow |
| Muted | `rgba(255,255,255,0.48-0.78)` |
| Accent cool | `#BAD2FF` / `#7DD3FC` |
| Success mute | `#C8F5E4` |
| Progress | violet → cyan → mint |

**Liquid glass stack (mandatory - Super Frontend / LG):**
1. Translucent fill + `backdrop-filter: blur(26px) saturate(185%)` so film shows through
2. Iridescent rim wash (cyan / violet / rose - edge, not full wash)
3. Specular top-edge catch + hairline porcelain rim
4. Soft outer glow depth shadow
5. `prefers-reduced-transparency` → solid elevated slate card

**Anti-slop hard ban:** opaque white cards on white canvas, empty sparse marketing fluff, toy bar charts as the only content, purple mesh sludge, emoji, rainbow H1, left-only essay, Prism both-side constellation clone, Meridian dark-gold coastal clone.

**Differentiation:**
| vs | Folio must not become |
|----|------------------------|
| Prism | Multi-face hero + both-side floating panels |
| Meridian | Dark coastal multi-chapter estate scrub |
| Revel | Pearl fashion scroll scrub |
| Apex | Quantum lab cyan void |

## Layout Structure

- **Section only** - no forced page intro/outro in the component
- **Scroll track:** ~`5 × 1.55 × 100vh` (sticky stage inside)
- **Sticky stage:** `100vh`, video cover + soft veil
- **Header:** kicker + heading above deck
- **Deck:** ~980×560 large glass sheet (absolute stack, hidden deck)
- **Footer chrome:** step label, dots, progress bar, quiet scroll hint
- **Safe insets:** stage column `min(1080px, 94vw)`; sheet pad `clamp(1.4rem, 2.8vw, 2.35rem)`

## Motion Specification

**Mode:** Scroll-linked paper pivot (Framer Motion `useScroll` / `useTransform`). **Not** video scrub. Video is muted loop wallpaper under glass.

| Local t | rotateX | opacity | note |
|---------|---------|---------|------|
| 0 | +72° | 0 | edge below |
| 0.22-0.78 | ~0° | 1 | face-on plateau |
| 1 | −72° | 0 | edge above |

- Local progress: ~18% overlap between sheets; **smoothstep** easing on segment map
- Dense rotate / opacity / y / scale keyframes (no hard jump)
- Y travel ~36px; scale 0.96→1→0.96
- Last sheet holds face longer then soft exit
- Progress bar `scaleX(scrollYProgress)`
- **Reduced motion:** static stacked glass cards, gradient fallback (no video), auto height

## Accessibility

- `prefers-reduced-motion` static path
- `prefers-reduced-transparency` solid cards
- Semantic `section` / `article` / headings
- Step label `aria-live="polite"`
- Focus not trapped; decorative layers `aria-hidden`

## Performance Notes

- One heavy glass surface face-on at a time (hidden deck)
- Animate transform/opacity only (no layout thrash)
- Video single element, cover scale 1.04 to hide edges
- font-display: swap
- will-change limited to sheet transform/opacity
