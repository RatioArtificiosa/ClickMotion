## Promise (buyer-facing)

**FOLIO** is a mid-page **pin-until-complete** liquid glass **decision section**: one full-viewport stage, five dense board-ready panels (Mandate → Outcomes), free-play motion film under glass. Wheel and trackpad advance **virtual progress**. Not a tall multi-page scroll. Not a hero.

**Pin freeing (mandatory).** After the last panel, scrolling down releases the pin. Then the **page owns** the wheel until the stage docks at the top (`stage.top >= 0`). Scrolling up in the next section must move the page, not rewind the cards. Pointer on the next sibling never drives the panels.

**How you build it:** download the product pack. Tell your AI: *Build FOLIO using the files in this folder. Read PROMPT.md. Keep pin-until-complete. After release at the end, the page owns scroll until the stage docks (top >= 0). Do not restore a tall multi-vh sticky track.*

## Interaction law (non-negotiable)

1. **Pin-until-complete** (PRODUCT_LAW). One `100dvh` stage. **Never** a tall multi-vh document track.  
2. Wheel / trackpad / touch / keys advance `journeyProgress` **0→1** (virtual distance ≈ sheets × 1.55 × viewport height).  
3. At progress **0 + scroll up** or **1 + scroll down**, **do not preventDefault** - host page continues.  
4. After release at **g = 1 + down**, the **page owns** wheel / touch / keys until the stage docks (`top >= -2`). Pointer on the next sibling never drives the cards.  
5. Map global progress → per-sheet local 0→1 with ~**18% overlap** + **smoothstep**.  
6. Film free-plays muted. **Never** set `video.currentTime` from progress.  
7. Capture: `window.__msScrollNarrative = { setProgress, getProgress, getTarget, pageOwns, productId: "MS-SEC-FOLI01" }`. Root: `data-folio-drive="pin"`. After release: `data-folio-owns="page"`.  
8. Reduced motion: static stacked cards, no pivot, gradient fallback.

## Motion Specification

**Mode:** **Pin-until-complete** paper pivot (Framer Motion `useMotionValue` journey progress + `useTransform`). Wheel / trackpad / touch / keys advance virtual progress **0→1**. **Not** tall multi-vh page scroll. **Not** video scrub. Video is muted loop wallpaper under glass.

| Local t | rotateX | opacity | note |
|---------|---------|---------|------|
| 0 | +72° | 0 | edge below |
| 0.22-0.78 | ~0° | 1 | face-on plateau |
| 1 | −72° | 0 | edge above |

- Virtual journey effort ≈ `sheets × 1.55` viewports of wheel/trackpad (not document height)
- Local progress: ~18% overlap between sheets; **smoothstep** easing on segment map
- Dense rotate / opacity / y / scale keyframes (no hard jump)
- Y travel ~36px; scale 0.96→1→0.96
- Last sheet holds face longer then soft exit
- Progress bar `scaleX(journeyProgress)`
- Capture helper: `window.__msScrollNarrative` (includes `pageOwns`)
- **Pin freeing:** after g=1 + down, page owns until dock
- **Reduced motion:** static stacked glass cards, gradient fallback (no video), auto height
