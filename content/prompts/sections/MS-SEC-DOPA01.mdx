## Promise (buyer-facing)

**Dopamine** is a **complete fashion footer** that closes a page with couture confidence. Dual navigation, an exclusion-blend wordmark, a living hero figure, a Lottie discount badge, letter scramble on enter, and a subscribe form that feels like the brand - not a generic SaaS bar.

**Why use it:**
- Your last screen becomes a brand moment, not an afterthought
- Scramble + Lottie + figure deliver motion luxury without WebGL
- Every label, figure, badge, and credit line is meant to be restaged
- One self-contained footer with no required site chrome above it

**How you build it:** download the product pack (prompt + source + figure + masks + Lottie). Tell your AI: *Build Dopamine footer using the files in this folder. Read PROMPT.md.*

## Design System

**Aesthetic Direction:** dark couture stage, mono legal type, heavy geometric wordmark, soft figure photography, red accent for emphasis only.

**Craft direction:** European fashion e-com close × high-end campaign end-card. Calm until scroll arrives - then the system wakes.

**Do not:**
- Use Tailwind `.container` (breaks width - use **`dop-container`** only)
- Strip scramble, Lottie, or the figure for a "simple" footer
- Add external hyperlinks unless the buyer explicitly wants them
- Ship storefront preview videos as rebuild media
- Hardcode Club GSAP plugins

**Differentiation:**

| vs | Dopamine must not become |
|----|--------------------------|
| Helix | Mid-page WebGL gallery |
| Studio Sequence | Scroll camera billboard |
| Phobia | Pointer-flee void stage |
| Generic site footer | Static link columns without motion system |

## Layout Structure

- **Footer only** - full width, CSS-masked stage, overflow hidden
- **Figure** absolute, height-driven (desktop ~65rem)
- **Discount** absolute Lottie badge (canvas renderer)
- **Container** (`dop-container`): dual nav → wordmark → subscribe + form → legal row
- **Credits** overlay panel (dialog), no site header required above

## Motion Specification

**Mode:** scroll-enter once (not scroll-scrub film, not pointer flee).

| Event | Feel |
|-------|------|
| Footer enters (`top 80%`, once) | Logo rises (yPercent 300→0), figure enters (100→0) |
| Same enter | Form fades in; subscribe title scaleY 0→1 |
| Same enter | Nav + bottom rows letter-scramble into place |
| Lottie enter | Badge plays to mid (desktop) or full (coarse pointer) |
| Desktop hover on badge | Frame range advances / returns |
| Reduced motion | Settled readable footer; no scramble thrash; no entrance offsets |

**Timing anchors:** logo/figure ~1.2s `power3.out`; form ~2s; title ~0.8s from +0.4s; scramble ~0.18s/char with stagger 0.04s.

## Responsive Behavior

- **Mobile:** full-width stage, mobile mask, figure composition retained, no hover Lottie scrub
- **Tablet:** tablet mask + intermediate fluid rem scale
- **Desktop:** desk mask, tall figure (~65rem), hover Lottie frame control
- **Ultrawide:** fluid rem keeps type and layout intentional (not a Tailwind max-width cage)
- **Reduced motion:** final composition visible without entrance thrash

## Accessibility

- Footer is semantic `<footer>`; logo has `aria-label`
- Decorative figure and masks use empty `alt` unless buyer supplies meaning
- Credits panel is a dialog with `aria-modal`, close control, and inert when closed
- Form uses native email validation + visible error text
- Default links are `#` with `preventDefault` - no surprise external navigation
- Respect `prefers-reduced-motion: reduce`

## Performance Notes

- GSAP transforms for enter motion; Lottie canvas for the badge only
- Prefetch Lottie on mount so enter feels snappy
- Cleanup kills timeline, Lottie instance, and hover listeners on unmount
- Optimize figure PNG; keep mask webps lean
- No Three.js / WebGL required
