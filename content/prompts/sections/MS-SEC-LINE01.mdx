## Promise (buyer-facing)

**Lineup** is a mid-page **product reveal section** where scroll becomes a private tasting of your range. The stage pins. Each scroll segment lands a new SKU: 3D vessel cross-fades, bloom tint shifts, copy card rebuilds, ghost number breathes. Visitors do not swipe a flat carousel of thumbnails. They meet each product with intention.

**Why use it:**
- Your line (2, 3, 5, or more) feels curated and premium, not grid-dumped
- Scroll owns the pacing so each product gets a full beat
- 3D vessel + editorial copy + optional spec sheet read as commerce-ready craft
- Every string, SKU count, mesh, label map, color, and spec row is meant for your brand
- Drop-in section after a hero or before shop - not a full homepage

Default demo (ACTUALLY Clear / Dawn / Dusk cans) is only a starting board. Tell your AI to restage products, expand the count, or swap the vessel type until it is unmistakably yours.

## Design System

**Aesthetic Direction:** **Lineup** - mid-page **product line scroll reveal** (not a full-bleed hero). Bone paper stage `#efede6`. Left: SKU wordmark, giant product name with accent period, italic pair line, pitch, optional spec rows. Right: WebGL product mesh with ghost giant number and soft bloom. Desktop pin ~`N × 100vh` with snap. Mobile: horizontal snap cards.

**Famous-UI craft direction:** premium CPG tasting room × Swiss editorial type × quiet 3D product photography. Calm. Expensive. Readable.

**Typography:**
- Section H2: light display serif, `clamp(32px, min(4.6vw, 6.5vh), 64px)`
- Product name: display light, `clamp(52px, min(7.6vw, 12vh), 128px)`, accent period in bloom color
- Wordmark SKU line: heavy geometric sans 15-17px
- Spec rows: tabular nums 15px + 12px labels

**Color tokens (defaults - replace freely):**
| Token | Default | Change to |
|-------|---------|-----------|
| Stage bone | `#efede6` | Your paper |
| Ink | `#1a1b1d` | Your type |
| Mist | `#6a6965` | Meta |
| Per-SKU bloom | per product `bloomColor` | Brand accents |

**Anti-slop hard ban:** purple mesh, emoji, Motionsites pill docks, auto-rotating carousel without scroll pin, leaving ACTUALLY demo copy for another brand, hardcoding "always 3" when the buyer needs 5+.

**Differentiation:**

## Layout Structure

- **Section only** - no forced site chrome
- **Desktop:** pin `top top`, end `+= N * 100vh` where N = product count, scrub + snap
- **Grid:** copy `5fr` / stage `7fr`
- **Mobile:** horizontal snap cards, swipe to change SKU
- **Tabs:** SKU numbers (01 02 03…) jump to pin progress
- **Keyboard:** ArrowLeft / ArrowRight while section in view

## Expand to more products (critical)

The section is **data-driven** by the `PRODUCTS` array. `LineupSection` uses `COUNT = PRODUCTS.length` for pin, snap, tabs, blooms, ghosts, and mobile cards.

1. **Add a product:** append an object with all `LineupProduct` fields (include `labelPath`).
2. **Pin length** becomes `N × viewport height` automatically (`end: += N * innerHeight`).
3. **Snap points** become `0, 1/N, 2/N, …, 1` via `snapPoints(COUNT)`.
4. **Tabs, ghosts, blooms, 3D stage** map over the array - no hand-edit of magic `3`.
5. **Recommended range:** 2–6 for comfort; 7–8 possible if copy stays short.
6. **H2 / eyebrow:** rewrite via `SECTION_META` (helper: `suggestedMetaForCount(n)` in data file).
7. **Labels:** set `labelPath` per product OR add keys to `LABEL_MAP` in `Can3D.tsx`.
8. **Reduce products:** delete array entries - pin shortens.
9. **Never** leave "Three formulations." when N ≠ 3.

Ask your AI: *“Expand Lineup from 3 to 5 products using this data: [list]. Update SECTION_META H2 to Five expressions. Keep pin snap and 3D cross-fade. Add labelPath for each new SKU.”*

## Motion Specification

**Mode:** scroll-scrub pin + snap (desktop). Not free-play film.

| Event | Timing | Notes |
|-------|--------|-------|
| Pin | top top → += N·vh | scrub 1 |
| Snap | 0…1/N…1 | soft 0.25–0.55s |
| Product change | active index | can x/y/rot/scale/opacity cross-fade ~0.85s |
| Copy card | out 0.25s / in 0.45s stagger | data-stage-item |
| Bloom / ghost | 0.7–0.8s | per active SKU |
| Tabs / arrows | instant jump | keyboard + click |

### Expand from 3 to N products
```

```

### Reduce products
```

```

### Swap the 3D vessel for any product
```

Keep metal vs label materials (or simplify), studio HDRI, and stage cross-fade motion.

```

### Change copy system (not beverages)
```

```

### Brand + colors

```
Mount LineupSection below ActuallyHero on the same page. Shared Lenis + ScrollTrigger.
Keep both bone stages coherent. Do not nest site chrome inside either component.
```
