## Promise (buyer-facing)

**Lineup** is a mid-page **product reveal section** where scroll becomes a private tasting of your range. The stage pins. Each scroll segment lands a new SKU: 3D vessel cross-fades, bloom tint shifts, copy card rebuilds, ghost number breathes. Visitors do not swipe a flat carousel of thumbnails. They meet each product with intention.

**No Scroller (pin-until-complete).** Scroll aims virtual progress on **N viewports** (N = product count). The page does not physically scroll during the viewing. SKUs snap on lift. When the journey ends, the pin **releases**. Then the **page owns the wheel** until the stage docks at the top of the viewport again. Pointer on the next sibling never drives the lineup. Not a tall sticky track. Not GSAP ScrollTrigger pin. Not Lenis. Not PSAVE.

**Why use it:**
- Your line (2, 3, 5, or more) feels curated and premium, not grid-dumped
- Scroll owns the pacing so each product gets a full beat
- 3D vessel + editorial copy + optional spec sheet read as commerce-ready craft
- Every string, SKU count, mesh, label map, color, and spec row is meant for your brand
- Drop-in section after a hero or before shop - not a full homepage

Default demo (ACTUALLY Clear / Dawn / Dusk cans) is only a starting board. Tell your AI to restage products, expand the count, or swap the vessel type until it is unmistakably yours.

**How you build it:** download the product pack (prompt + source + mesh + labels + HDRI). Tell your AI: *Build Lineup using the files in this folder. Read PROMPT.md and follow it. Prefer source/LineupSection.tsx and source/lineup-data.ts. No Scroller: pin-until-complete. One 100dvh stage. Scroll aims virtual progress on N viewports. Snap on lift. At 0 plus up, or 1 plus down, release. After release at the end, the page owns scroll until the stage docks (top >= 0; implement >= -2). Do not install lenis. Do not build a tall multi-vh sticky track. Do not add PSAVE. Keep gsap for SKU cross-fade tweens only.*

## Expand to more products (critical)

The section is **data-driven** by the `PRODUCTS` array. `LineupSection` uses `COUNT = PRODUCTS.length` for pin, snap, tabs, blooms, ghosts, and mobile cards.

1. **Add a product:** append an object with all `LineupProduct` fields (include `labelPath`).
2. **Virtual earn** becomes `N × viewport height` automatically (not a document spacer).
3. **Snap points** become `0, 1/N, 2/N, …, 1` via `snapPoints(COUNT)`.
4. **Tabs, ghosts, blooms, 3D stage** map over the array - no hand-edit of magic `3`.
5. **Recommended range:** 2–6 for comfort; 7–8 possible if copy stays short.
6. **H2 / eyebrow:** rewrite via `SECTION_META` (helper: `suggestedMetaForCount(n)` in data file).
7. **Labels:** set `labelPath` per product OR add keys to `LABEL_MAP` in `Can3D.tsx`.
8. **Reduce products:** delete array entries - pin shortens.
9. **Never** leave "Three formulations." when N ≠ 3.

Ask your AI: *“Expand Lineup from 3 to 5 products using this data: [list]. Update SECTION_META H2 to Five expressions. Keep pin snap and 3D cross-fade. Add labelPath for each new SKU.”*

## Motion Specification

**Mode:** **No Scroller** = **pin-until-complete**. Virtual progress `g` 0→1 on **N viewports**. Snap on lift. Not PSAVE. Not a tall page track.

```
Earn desktop: VIRTUAL_VIEWPORTS = PRODUCTS.length
virtualDistance = VIRTUAL_VIEWPORTS * window.innerHeight
delta progress = wheelDeltaY / virtualDistance
Snap on lift to 0, 1/N, 2/N, …, 1
```

| Event | Timing | Notes |
|-------|--------|-------|
| Pin engage | section in view, journey not finished | consume wheel / touch / keys |
| Product change | `floor(g * N)` | can x/y/rot/scale/opacity cross-fade ~0.85s |
| Snap | 140ms after last gesture | nearest SKU stop |
| Copy card | out 0.25s / in 0.45s stagger | data-stage-item |
| Bloom / ghost | 0.7–0.8s | per active SKU |
| Release | g ≤ 0 + up, or g ≥ 1 + down | host page may continue |
| **Pin freeing** | after g = 1 + down | **page owns** until stage docks (`top >= -2`) |
| Tabs / arrows | jump `g` to i/N | keyboard + click |

**Hard ban:** GSAP `ScrollTrigger` pin + `pinSpacing`.
**Hard ban:** Lenis / SmoothScroll.
**Hard ban:** an N vh **document spacer** (N is **virtual earn** only).
**Hard ban:** installing `lenis`. gsap stays for SKU tweens only.
**Hard ban:** PSAVE / film reverse.
**Hard ban:** `overflow: hidden` on the host page.

Root marker: `data-lineup-drive="pin"` · `data-product="MS-SEC-LINE01"`. After release: `data-lineup-owns="page"`. Capture helper: `window.__msScrollNarrative = { setProgress, getProgress, getTarget, pageOwns, productId: "MS-SEC-LINE01" }`.

**Reduced motion:** first product static, readable copy. No chase.

**Confirm (desktop 900px tall, N = 3):** two 1800px flicks = `g = 1.0` with page `scrollY` still 0. One more down-scroll releases. First up after release moves the page, not the lineup.
