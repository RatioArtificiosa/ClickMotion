## Promise (buyer-facing)

**Studio Sequence** is a mid-page (or hero) **cinematic camera pull-out**. Visitors open *inside* your film - full bleed, no street, no frame. As they scroll, the world scales out around the billboard center until the same film is still playing on a facade screen in a living street.

**Why use it:**
- Your film becomes architecture, not a flat `<video>` tag
- **Any video** drops in - campaign, manifesto, AI b-roll, product film
- **Full length** - the section never trims or seek-scrubs your file
- Scroll owns the camera only - film time runs free for the wow factor
- One React section - not a full homepage

Default demo uses the **Surreal Studio pure film** (no UI chrome) on an NY street plate. Tell your AI to swap the film path and keep the pull-out math.

**Live demo:** `/demo/cleanroom-studio`  
**Deep AI guide:** `cleanroom/studio-from-prompt/CUSTOMIZATION.md`

## Design System

**Aesthetic Direction:** **Studio Sequence** - world-scale camera, street plate, LED billboard glass. Black stage. No chrome required in production.

**Famous-UI craft direction:** luxury outdoor advertising × film-title open × quiet city still. Expensive. Unhurried. Full film length.

**Anti-slop hard ban:** shrinking free-floating video rect (must be world scale), scroll-scrubbing `currentTime`, CSS color grades without buyer request, UI-framed storefront captures as the billboard film, trimming long films for "performance" without buyer OK.

**Differentiation:**
| vs | Studio Sequence must not become |
|----|----------------------------------|
| Meridian / Elyse | Multi-panel copy scroll narrative |
| Lumina | Studio-lot hero without billboard lock |
| Lineup | 3D product SKU pin |
| Flat hero video | Static full-bleed without pull-out |

## Layout Structure

- **Section only** - no forced site chrome
- **Pin** `top top` → `end: +=280%` (configurable)
- **World layer** = plate + video shell locked to billboard rect
- **Scale** from four-edge cover → 1 around billboard center
- **Video** `object-fit: cover` inside board - any aspect ratio

## Content slots (every field is replaceable)

All buyer media + feel knobs live in **`studio-data.ts`**: `STUDIO_DEFAULTS`.

| Slot | Source | Guidance |
|------|--------|----------|
| Billboard film | `videoSrc` | **Any MP4** - full length |
| Poster still | `posterSrc` | Optional first paint |
| Street plate | `plateSrc` | 1920×1080+ still |
| Plate size | `plateWidth` / `plateHeight` | Natural pixels |
| Billboard rect | `billboard` | 0–1 fractions of plate (inner screen) |
| Pin length | `pinEnd` | e.g. `+=280%` |
| Scrub silk | `scrub` | default 1.15 |
| Hold in / out | `holdIn` / `holdOut` | full-bleed hold + street settle |
| Loop | `video.loop` | full file repeat |
| Appearance | `video.cssFilter` | **off by default** |

## Dynamic video (critical)

The section is **video-agnostic**. Change only `videoSrc` (and optional poster).

1. Drop film at `/assets/videos/[your-film].mp4`
2. Set `STUDIO_DEFAULTS.videoSrc` or pass `<StudioSequence videoSrc="…" />`
3. Keep `playFullLength: true` - never trim, never `#t=` fragments, never scroll-linked seek
4. Prefer H.264 yuv420p + faststart for autoplay
5. Long films (2+ minutes) are supported and encouraged for premium feel

### Use the included Surreal pure film
```
Keep videoSrc = /assets/videos/studio-surreal-v1.mp4
This is the pure Surreal Studio film (no UI frames), same source as Lab surreal.mp4.
Play full length with loop. Do not cut or regrade.
```

### Swap to any custom video
```
Set videoSrc to my file at [PATH or URL].
Optional posterSrc from a still of the same film.
Keep full-length loop, object-fit cover, camera pull-out math.
Do not seek video with scroll. Do not add CSS filters.
```

## Motion Specification

**Mode:** scroll-scrub pin. Film free-runs full length.

| Event | Timing | Notes |
|-------|--------|-------|
| Pin | top top → +=280% | scrub ~1.15 |
| Hold in | first ~6% | full-bleed film |
| Pull-out | middle | smootherstep scale |
| Hold out | last ~10% | settle on street |
| Film time | independent | 0 → duration → loop |
