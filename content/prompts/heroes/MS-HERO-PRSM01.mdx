## Design System

**Aesthetic Direction:** **PRISM** - liquid-glass multi-panel identity hero. Soft studio mist behind a centered multi-face sculpture. **Panels of many sizes float on LEFT and RIGHT** (chips, metrics, stats, profiles, quotes, features, CTAs). Scroll owns the film timeline. Material system: SVG distortion + shell + specular + stabilized content plate. Syne display + DM Sans. Prism violet / cyan accents.

**Famous-UI craft direction (not a clone):** Apple Liquid Glass material discipline (layers, light model, readability) × gallery installation pacing. Never a single left H1 column.

**Typography:**
- Display: Syne 600-700, tracking tight
- UI: DM Sans 400-600, 11-14px
- Chips: 10-11px uppercase tracking

**Color tokens:**
| Token | Value |
|-------|--------|
| Studio mist | `#E8EAEF` |
| Ink | `#0E1016` |
| Violet | `#A78BFA` |
| Soft violet | `#C4B5FD` |
| Cyan | `#67E8F9` |
| Fuchsia | `#F0ABFC` |
| Glass fill | `rgba(255,255,255,0.10-0.18)` |

**Liquid glass stack (mandatory):**
1. SVG `#prism-glass-distortion` once (turbulence + blur + displacement)
2. Shell with backdrop-filter blur + saturate
3. Specular top edge + hairline rim
4. Stabilized plate under type
5. Tiers thin / standard / thick
6. `prefers-reduced-transparency` solid fallback

**Layout law:** Center faces stay clear. Information lives in **both-side** floating panels. Top-center chapter pill. No left-only body dump.

**Chapters:**
1. 01 · Spectrum — open feature left, stats right
2. 02 · Margins — quote right, profile left, chips both sides
3. 03 · Clarity — feature left, CTA right

**Anti-slop hard ban:** left-column-only heroes, full-viewport frosted slab, purple mesh sludge, emoji, Meridian/Vertex/Neon/Revel clones, Apple trademarks.

**Differentiation:**
| vs | Prism must not become |
|----|------------------------|
| Revel | Pearl fashion left chapters |
| Meridian | Dark coastal estate |
| Vertex | Mono security scrub |
| Apex | Quantum cyan void |
| Neon | Rain megacity loop |

**Cursor / Claude / Grok Build:** Build `PrismLiquidGlass.tsx` from this brief only. Wire exact video paths. GSAP ScrollTrigger scrub is mandatory. Multi-panel both-side field is the signature. Liquid glass is a stack, not one blur.

1. Single React component `PrismLiquidGlass.tsx` (`"use client"`)
2. SVG filter once; tiered glass panels left + right
3. Scroll track ~520vh, sticky stage, scrub ~0.55
4. Reduced motion mid-frame; reduced transparency solid plates
5. No host marketing chrome inside the cleanroom component
