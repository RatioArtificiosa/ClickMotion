## Design System

**Aesthetic Direction:** **LUMINA STUDIOS** - film production / post house. Espresso canvas `#1E140A`, amber `#F59E0B`, cream `#FEF3C7`, Playfair Display + Inter. Full-viewport warm cinematic dolly, soft glass nav, unhurried entrances. Feels like a prestige craft house - not neon cyberpunk, not wellness cream, not brutalist security, not luxury coastal scroll.

**Famous-UI craft direction (not a clone):** Film studio launch page restraint (trailer calm + precise type). One video system. Soft entrances. Stop.

**Typography:**
- Display / H1: Playfair Display 700-900, tracking `-0.03em`, line-height `0.9`, size `clamp(2.75rem, 8vw, 7rem)`
- Body: Inter 300-400, 15-17px, line-height 1.65, cream at ~65%
- Badge / nav: Inter 10-12px, uppercase tracking `0.16-0.22em` on badge

**Color tokens:**
| Token | Value |
|-------|--------|
| Canvas | `#1E140A` |
| Amber | `#F59E0B` |
| Cream | `#FEF3C7` |
| Muted | `rgba(254,243,199,0.65)` |
| Glass | `rgba(254,243,199,0.04)` + blur |
| Scrim | left-heavy espresso gradients |

**Radius:** `rounded-full` on pills (soft studio chrome).  
**Spacing:** 8px grid. Safe horizontal inset minimum `px-8`.

**Anti-slop hard ban:** cyan/pink neon kits, purple mesh, shiny gradient text, emoji, Meridian multi-chapter scrub, Vertex zero-radius mono, Aether wellness ocean.

**Differentiation:**
| vs | Lumina must not become |
|----|------------------------|
| Neon Forge | Cyan-pink rain megacity glitch |
| Meridian | Gold coast multi-chapter scrub |
| Vertex | Monochrome security scrub |
| Aether | Cream wellness ocean |

## Motion Specification

Staggered Framer entrance (if not reduced motion): badge 0.55s, H1 0.75s delay 0.18, amber line 0.7s delay 0.28, body 0.6s delay 0.38, CTAs 0.55s delay 0.48. Ease `[0.25, 0.46, 0.45, 0.94]`. **No glitch.**

GSAP: video scale 1→1.05, scrub 1.2, desktop only. Reduced motion: fade only.
