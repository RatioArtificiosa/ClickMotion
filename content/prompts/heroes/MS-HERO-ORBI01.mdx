## Interaction law (non-negotiable)

1. Film free-plays muted loop. **Never** set `video.currentTime` from scroll.  
2. Framer stagger entrance on badge → H1 → lead → CTAs → proof.  
3. Orbital ring: slow continuous rotate (~64s) on UI geometry only (GSAP).  
4. Desktop: film wrap scale `1 → 1.05`, scrub `1.2`. Off below 768px.  
5. IntersectionObserver pause off-screen; kill GSAP + IO on unmount.  
6. Reduced motion: poster still, static ring, no parallax, full type.
