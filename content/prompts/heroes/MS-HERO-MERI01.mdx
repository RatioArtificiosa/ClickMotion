## Design System

**Aesthetic Direction:** Ultra-luxury private residences - **MERIDIAN**. Dark cinematic frame (`#0c0a08`) over a golden-hour Atlantic estate film. Cream type (`#f7f1e8`), single gold accent (`#c9a66b`). Editorial serif display (Cormorant Garamond or Playfair Display), Inter for UI. Quiet, expensive, unhurried - Aman / Four Seasons Residences craft × Apple product-film pacing. **Never** SaaS purple, aurora mesh, pill glass nav, border beams, shiny gradient text, or emoji.

**Famous-UI craft direction (not a clone):** Four Seasons Private Residences editorial calm + linear scroll storytelling (Cartier / Shopify Editions class restraint). One signature system: scroll owns the film via **pin-until-complete** virtual progress.

**Typography:**
- Display / H1: Cormorant Garamond (or Playfair Display), weight 500, tracking `-0.02em`, line-height `0.96`, size `clamp(2.75rem, 7.2vw, 5.85rem)`. Two stacked lines via block spans.
- Body: Inter 300-400, 15-17px, line-height 1.7, color cream at 78% opacity.
- Eyebrows / nav: Inter 10-11px, uppercase, tracking `0.18em-0.28em`, gold for active eyebrows.

**Color tokens:**
| Token | Hex |
|-------|-----|
| Canvas | `#0c0a08` |
| Cream | `#f7f1e8` |
| Gold | `#c9a66b` |
| Soft gold | `#e8d5b0`, `#f0d9a8` |
| Linear scrim | `rgba(8,6,4,0.55)` → mid open → bottom `0.72` |
| Radial vignette | soft ellipse, center clear |

**Spacing:** 8px grid. Content max-width `1400px`. **Safe horizontal inset minimum `px-8` / 2rem** (prefer `md:px-14` `lg:px-16`) so type never clips at frame edges or under gallery `object-cover` crop. Display type: `min-w-0`, `break-words`, clamp capped so lockups stay inside ~84% center. Nav height `4.5rem`. Rectangular CTAs (not pills) - border-radius `0`.

**Anti-slop hard ban:** floating glass pill dock nav, mesh/aurora/warp backgrounds, shiny text, marquee, bento clutter, Inter-only heavy bold H1, more than one gold system.

**Closing band:** Dark canvas, gold "Membership" eyebrow, display headline "Reserved for those / who already have everything.", supporting copy, stats `12 Residences · 4 Coastlines · 100% Owners only`, outlined gold "Begin a conversation" mailto.

## Motion Specification

**Signature mode: scroll-as-narrative · pin-until-complete.** Virtual progress 0→1 drives `video.currentTime`. Video never autoplays and never loops as wallpaper.

**Hard ban:** tall multi-vh document scrollbar track (legacy `420vh` sticky pattern). **Method only changed** - gold effort and lag stay:

```tsx
// Pin-until-complete - virtual progress owns the film
const VIRTUAL_VIEWPORTS = 3.2; // GOLD: ≡ old 420vh track scroll distance
const SCRUB_LAG = 0.45;        // GOLD: same feel as ScrollTrigger scrub: 0.45

// Wheel / touch / keys → targetProgress
// gsap.to(proxy, { p: target, duration: SCRUB_LAG, ease: "none", onUpdate: apply })
// apply: video.currentTime = p * duration when |Δt| > 0.016
// Release at progress 0 + scroll up, or progress 1 + scroll down (host page continues)
// Optional: window.__msScrollNarrative = { setProgress, getProgress }
// video: muted playsInline preload="auto" - no autoPlay, no loop; always pause()
```

| Motion | Spec |
|--------|------|
| Stage | **Pinned `100dvh`** - one frame, no tall track |
| Virtual viewports | **`3.2`** (gold pace - do not change) |
| Scrub lag | **`0.45`** (GSAP progress proxy tween) |
| Chapter enter | opacity 0→1, y 18→0, 0.85s, `cubic-bezier(0.22, 1, 0.36, 1)` |
| Progress bar | direct `scaleX(progress)`, origin left |
| Scroll cue | visible only when progress &lt; 0.04; thin pulsing gold line under the word SCROLL |
| Capture API | `window.__msScrollNarrative.setProgress(0..1)` for burns |
| Reduced motion | No scrub; poster + chapter 01 still |

No Framer layout animations required. Optional CSS keyframes for chapter crossfade only.

## Accessibility

- Honor `prefers-reduced-motion: reduce` - static chapter 01, no virtual scrub
- Semantic `header`, `section`, `h1`, real focusable links for all CTAs
- Cream text on dark scrim meets contrast; never thin gray on bright sky without scrim
- Pin consumes wheel/touch while journey runs; **releases** at ends so page can continue (membership band). Do not trap focus.
- Progress bar is decorative; chapters readable without color alone (numbers 01-03)

## Performance Notes

- Single `<video>`; always paused; seek only when `|Δt| > 0.016s`
- Kill GSAP scrub tween on unmount
- Poster first paint; `preload="auto"` acceptable for this hero
- Cap re-renders: chapter state changes only when index changes
- One WebGL/canvas forbidden for this SKU - video + DOM only
- Prefer mid-weight encode (~10-20MB) with dense keyframes over 4K 50MB+
