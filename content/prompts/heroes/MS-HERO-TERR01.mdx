## Design System

**Aesthetic Direction:** **TERRA NOVA** - clean energy / climate-tech platform. Deep forest canvas `#0B1A14`, living sage `#7BA58F`, soft solar gold `#E8B86D`, cream headlines `#F4F7F2`. Fraunces display + DM Sans UI. Full-viewport aerial renewable landscape, soft green glass nav, unhurried entrances. Feels like serious climate brand craft - not wellness cream spa, not neon cyberpunk, not film-lot amber, not brutalist security, not luxury coastal scroll.

**Famous-UI craft direction (not a clone):** Climate-tech launch restraint (National Geographic calm + product precision). One video system. Soft entrances. Stop.

**Typography:**
- Display / H1: Fraunces 600-700, tracking `-0.02em`, line-height `0.95`, size `clamp(2.75rem, 8vw, 7rem)`
- Body: DM Sans 300-400, 15-17px, line-height 1.65, cream at ~68%
- Badge / nav: DM Sans 10-12px, uppercase tracking `0.16-0.22em` on badge

**Color tokens:**
| Token | Value |
|-------|--------|
| Canvas | `#0B1A14` |
| Sage | `#7BA58F` |
| Solar gold | `#E8B86D` |
| Cream | `#F4F7F2` |
| Muted | `rgba(244,247,242,0.68)` |
| Glass | sage-tinted blur |
| Scrim | left-heavy forest gradients |

**Radius:** `rounded-full` on pills.  
**Spacing:** 8px grid. Safe horizontal inset minimum `px-8`.

**Anti-slop hard ban:** cyan/pink neon kits, purple mesh, shiny gradient text, emoji, Aether cream wellness, Lumina film-lot amber system, Meridian multi-chapter scrub, Vertex zero-radius mono.

**Differentiation:**
| vs | Terra Nova must not become |
|----|----------------------------|
| Aether | Cream wellness ocean / meditation spa |
| Lumina | Amber espresso studio lot |
| Neon | Cyan-pink rain megacity glitch |
| Meridian | Gold coast multi-chapter scrub |
| Vertex | Monochrome security scrub |

## Motion Specification

Staggered Framer entrance (if not reduced motion): badge 0.55s, H1 0.75s delay 0.18, gold line 0.7s delay 0.28, body 0.6s delay 0.38, CTAs 0.55s delay 0.48. Ease `[0.25, 0.46, 0.45, 0.94]`. **No glitch.**

GSAP: video scale 1→1.05, scrub 1.2, desktop only. Reduced motion: fade only.
