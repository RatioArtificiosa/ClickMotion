## Promise (buyer-facing)

**BLOOM** is a full-viewport **kids and teen girls yoga course + app hero**: sunlit multi-girl class film, warm paper and lilac craft, peach CTAs, and a signature **Kids / Teens** path that restages badge, titles, modules, phone card, and CTAs over a living free-play film. Soft staggered entrance. Optional desktop film-wrap parallax only. Never scrub.

**Why use it:**
- Kids / teen wellness, yoga course, and girl-app brands that sell **belonging as craft**
- Dual-age path no single-static hero can match
- Plus Jakarta soft geometric restages cleanly for any soft-premium education brand
- Client HD is pure class film (no burnt UI); storefront dual previews are separate

Default copy (**Soft strength. / Big smiles.** through **Your calm. / Your circle.**) is a starting board. Restage paths, modules, CTAs, and stats until it is unmistakably yours.

**How you build it:** download the product pack (prompt + source + film). Tell your AI: *Build BLOOM using the files in this folder. Read PROMPT.md.*

## Design System

**Aesthetic Direction:** Soft kids education prestige meets beauty-commerce warmth. Canvas paper `#fff8f5`, ink `#2a2438`, lilac `#c4a8e8`, peach CTA `#ffb5a7`, butter kids accent `#ffe8a3`, soft mint teens `#b8e0d2`. Plus Jakarta Sans (or equal soft geometric) for display and body. Cream glass pills, soft shadows. **Not** adult night spa, neon mesh, emoji kids junk, or body-shame fitness.

**Famous-UI craft direction (not a clone):** Premium kids education homepage bar + soft beauty commerce + class-card fitness clarity. One signature system: free-play class film + dual-age path restage.

## Interaction law (non-negotiable)

1. Film free-plays muted loop (class energy). **Never** set `video.currentTime` from scroll.
2. Soft staggered entrance for type + chips + CTAs (~0.7s ease).
3. Kids / Teens toggle restages badge, H1, body, modules, whisper, CTAs, phone card (film continuous).
4. Module chips update phone card active class.
5. Dual CTAs always visible: free class + get/download app.
6. Desktop only optional: GSAP scale film wrap 1 → 1.05 scrub ~1.2 on section.
7. `prefers-reduced-motion`: poster still, no stagger, no parallax, video paused.
8. IntersectionObserver: pause when off-screen, play when visible.

## Motion Specification

**Mode:** Free-play muted class film + Kids/Teens path restage. **Not** scroll-scrub. **Not** STILL hybrid Option A.

| Layer | Spec |
|-------|------|
| Film | autoPlay muted loop playsInline preload auto; object-fit cover |

| Modules | Chip select updates phone card only |
| Desktop parallax | Optional GSAP scale wrap `1 → 1.05`, scrub ~1.2; **never** `video.currentTime` |
| Mobile | No wrap parallax under 768px; hide center nav; stack CTAs |
| Off-screen | IntersectionObserver pause / play (threshold ~0.12) |
| Reduced motion | Poster still; no stagger; no parallax; video paused |
