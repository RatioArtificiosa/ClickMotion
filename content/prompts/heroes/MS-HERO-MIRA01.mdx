## Promise (buyer-facing)

MIRAGE is a full-viewport **agency hero**. Desert film plays freely on the right. Five morphic liquid-glass story cards pivot on the left. Visitors do not scrub a film. They move through a crafted deck of work while the heat-haze subject holds the frame.

**No Scroller (pin-until-complete).** Scroll aims the cards. The page does not physically scroll during the viewing. When the journey ends, the pin **releases**. Then the **page owns the wheel** until the stage docks at the top of the viewport again. Pointer on the next sibling never drives the cards. Not a tall sticky track. Not GSAP ScrollTrigger. Not PSAVE. The film does not rewind.

**Why use it:**
- Your agency or studio feels like a private screening, not a stock carousel
- Scroll owns the cards so each sheet gets a full beat
- Film stays cinematic because it free-plays; cards stay intentional
- Every string, metric, chip, and the film itself is meant to be replaced with your brand
- Built for ad agencies, brand studios, and campaign houses that sell craft with heat and restraint

Default demo content (MIRAGE wordmark, sample agency sheets, "Creative that / survives the heat.") is only a starting board. Tell your AI to restage everything until it reads as you alone.

**How you build it:** download the product pack (prompt + source + desert film). Tell your AI: *Build MIRAGE using the files in this folder. Read PROMPT.md and follow it. Prefer source/MirageAgencyHero.tsx. No Scroller: pin-until-complete. One 100dvh stage. Scroll aims virtual progress on 5 x 1.55 viewports. Cards follow that progress 1:1. Film free-plays muted. At 0 plus up, or 1 plus down, release. After release at the end, the page owns scroll until the stage docks (top >= 0). Do not restore a tall multi-vh sticky track. Do not add PSAVE. Do not scrub video.currentTime.*

## Design System

**Aesthetic Direction:** **MIRAGE** - advertising-agency full-viewport hero. Free-playing desert film with the subject held on the **right**. Left rail only: kicker, two-line large headline, five morphic dark liquid-glass pivot cards, centered progress footer. Minimal text nav. Syne (or geometric display) + clean sans. Gold + cyan accents on near-white type.

**Famous-UI craft direction (not a clone):** Triada / M.A.C. morphic glass stack (dark translucent fill + strong blur + saturate) x private-bank pacing x ad-film craft. Not white frost. Not Motionsites pill dock.

**Typography:**
- Display / H1: Syne 600, tracking `-0.04em`, `clamp(2.15rem, 4.4vw, 3.55rem)`, line-height ~0.92, **exactly two lines**
- Sheet titles: Syne 600, `clamp(1.18rem, 2.05vw, 1.48rem)`
- Body / lead: 13px, line-height 1.55
- Labels / chips: 9-11px uppercase tracking `0.1-0.22em`
- Metrics: Syne 700, tabular nums

**Color tokens:**
| Token | Value |
|-------|--------|
| Stage ink | `#07080F` |
| Glass fill | `rgba(28, 30, 42, 0.38)` |
| Glass blur | `blur(36px) saturate(190%)` |
| Type | `#FAF8F5` / `rgba(255,255,255,0.94)` |
| Gold accent | `#FDE68A` |
| Cyan accent | `#7DD3FC` |
| Chip surface | `rgba(255,255,255,0.08)` |

**Morphic liquid glass stack (mandatory - M.A.C.):**
1. Shell: radius ~22px, hairline rim, depth shadow
2. Fill: dark translucent slate + `backdrop-filter: blur(36px) saturate(190%)`
3. Specular: top-edge catch + diagonal highlight only (not a white wash)
4. Body content **above** glass layers (never text on the blur node)
5. Nested chips: light translucent surfaces
6. Do **not** kill glass via `prefers-reduced-transparency` on this product (Windows transparency-off was producing solid dark slabs). Reduced-motion remains static cards.

**Anti-slop hard ban:** white frosted cards, opaque black plates, purple mesh sludge, emoji, rainbow H1, Motionsites pill nav, left-only sparse marketing fluff, Prism both-side constellation clone, Folio mid-page section framing as if this were a section.

## Motion Specification

**Mode:** **No Scroller** = **pin-until-complete**. Cards are driven by **virtual progress** `g` 0→1. Film is **not** on that clock.

```
Earn: VIRTUAL = max(2.4, sheets × 1.55) viewports
virtualDistance = VIRTUAL * window.innerHeight
delta progress = wheelDeltaY / virtualDistance
```

Gestures map **1:1** onto that distance. No wheel gain. Old `useScroll` feel: cards follow `g` immediately through the same rotateX maps.

| Event | Timing | Ease / notes |
|-------|--------|--------------|
| Pin engage | section in view, page does not own the wheel | consume wheel / touch / keys |
| Sheet local `t` | each sheet maps a slice of `g` with ~16% pad overlap | smoothstep on the segment |
| Sheet 0 open | starts near face-on (`from ~0.38`) | hero never opens empty |
| rotateX | +64° → 0° face plateau → −64° | last sheet holds face longer |
| opacity / scale / y / z | same keyframes as pack source | transform + opacity only |
| Progress bar | `scaleX(g)` | footer under cards |
| Release | g ≤ 0 + up, or g ≥ 1 + down | do not preventDefault |
| **Pin freeing** | after release at **g = 1 + down** | **page owns** wheel / touch / keys |
| **Dock** | stage `getBoundingClientRect().top >= 0` (use `>= -2`) | page-owns clears; pin may take the wheel again |
| Pointer on next sibling | never | runway / after-band never drives cards |

**Pin freeing (mandatory, do not skip):**

Once the last card has closed and the visitor scrolls **down**, the pin **releases**. From that moment the **page** owns scroll. Scrolling **up** in the next section must move the **page**, not rewind the cards. The pin may take the wheel again only after the stage **docks** at the top of the viewport. If the pointer is on the next sibling, never consume the gesture.

```
pageOwns = false
on each gesture:
  if stage.top >= -2: pageOwns = false
  if pageOwns: do not preventDefault; return
  if g >= 1 and delta > 0: pageOwns = true; do not preventDefault; return
  if g <= 0 and delta < 0: do not preventDefault; return
  else: apply delta to g; preventDefault
```

**Hard ban:** Framer `useScroll` on a tall document spacer.
**Hard ban:** a 5 × 1.55 vh **document spacer** as the method (those numbers are **virtual earn** only).
**Hard ban:** keeping the pin armed after release so up-scroll in the runway rewinds the sequence.
**Hard ban:** PSAVE / GOP 3 / reverse film. Mirage film free-plays. It does not rewind.
**Hard ban:** mapping scroll to `video.currentTime`.
**Hard ban:** `overflow: hidden` on the host page.
**Hard ban:** installing `gsap` or `lenis` for this hero.

Root marker: `data-mirage-drive="pin"`. After release: `data-mirage-owns="page"`. While the pin owns: `data-mirage-owns="pin"`. Capture helper: `window.__msScrollNarrative = { setProgress, getProgress, getTarget, pageOwns, productId: "MS-HERO-MIRA01" }`.

**Reduced motion:** static stacked glass cards, gradient fallback, no video chase.
