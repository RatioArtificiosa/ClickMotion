## Design System

**Aesthetic Direction:** **MIRAGE** - advertising-agency full-viewport hero. Free-playing desert film with the subject held on the **right**. Left rail only: kicker, two-line large headline, five morphic dark liquid-glass pivot cards, centered progress footer. Minimal text nav. Syne (or geometric display) + clean sans. Gold + cyan accents on near-white type.

**Famous-UI craft direction (not a clone):** Triada / M.A.C. morphic glass stack (dark translucent fill + strong blur + saturate) x private-bank pacing x ad-film craft. Not white frost. Not Motionsites pill dock.

**Typography:**
- Display / H1: Syne 600, tracking `-0.04em`, `clamp(2.15rem, 4.4vw, 3.55rem)`, line-height ~0.92, **exactly two lines**
- Sheet titles: Syne 600, `clamp(1.18rem, 2.05vw, 1.48rem)`
- Body / lead: 13px, line-height 1.55
- Labels / chips: 9-11px uppercase tracking `0.1-0.22em`
- Metrics: Syne 700, tabular nums

**Color tokens:**
| Token | Value |
|-------|--------|
| Stage ink | `#07080F` |
| Glass fill | `rgba(28, 30, 42, 0.38)` |
| Glass blur | `blur(36px) saturate(190%)` |
| Type | `#FAF8F5` / `rgba(255,255,255,0.94)` |
| Gold accent | `#FDE68A` |
| Cyan accent | `#7DD3FC` |
| Chip surface | `rgba(255,255,255,0.08)` |

**Morphic liquid glass stack (mandatory - M.A.C.):**
1. Shell: radius ~22px, hairline rim, depth shadow
2. Fill: dark translucent slate + `backdrop-filter: blur(36px) saturate(190%)`
3. Specular: top-edge catch + diagonal highlight only (not a white wash)
4. Body content **above** glass layers (never text on the blur node)
5. Nested chips: light translucent surfaces
6. Do **not** kill glass via `prefers-reduced-transparency` on this product (Windows transparency-off was producing solid dark slabs). Reduced-motion remains static cards.

**Anti-slop hard ban:** white frosted cards, opaque black plates, purple mesh sludge, emoji, rainbow H1, Motionsites pill nav, left-only sparse marketing fluff, Prism both-side constellation clone, Folio mid-page section framing as if this were a section.

**Differentiation:**
| vs | Mirage must not become |
|----|------------------------|
| Folio | Mid-page section, enterprise decision board |
| Prism | Multi-face + both-side floating panels |
| Meridian | Dark coastal multi-chapter scrub estate |
| Neon Forge | Cyan/pink liquid-glass pill SaaS game studio |

## Layout Structure

- **Hero:** full-viewport sticky stage inside tall scroll track (~`5 x 1.35 x 100vh`)
- **Grid:** left rail (~1fr, max ~540px visual, optional `zoom: 1.2` composition) + right subject space
- **Nav:** absolute top, text-only brand + links, no bar
- **Rail intro:** kicker + two-line H1 (`white-space: nowrap` per line)
- **Deck:** ~430px / 50vh height absolute stack of five glass sheets
- **Footer under cards:** centered progress bar, dots, active label, scroll hint
- **Safe insets:** stage padding `clamp` horizontal; type never flush to edge

## Motion Specification

**Mode:** Scroll-linked glass card pivot (Framer Motion `useScroll` / `useTransform`). **Not** video scrub. Video is free-playing muted loop wallpaper under glass.

| Local t | rotateX | opacity | note |
|---------|---------|---------|------|
| 0 | +64° | 0 | edge below |
| ~0.38-0.55 | ~0° | 1 | face-on plateau |
| 1 | −64° | 0 | edge above |

- Local progress with soft pad overlap between sheets; smoothstep on segment map
- Sheet 0 starts near face-on (`from ~0.38`) so open state never empty
- Dense rotate / opacity / y / scale / contentOpacity keyframes
- Y travel ~26px; scale 0.975→1→0.975
- Progress bar `scaleX(scrollYProgress)`
- **Reduced motion:** static stacked glass cards, gradient fallback (no video)

## Accessibility

- `prefers-reduced-motion` static path
- Semantic `section` / `nav` / `article` / headings
- Decorative glass layers `aria-hidden`
- Focusable text links in nav
- Contrast: near-white type on dark glass + scrim

## Performance Notes

- One heavy glass surface face-on at a time (hidden deck)
- Animate transform/opacity only
- Video single element, cover scale ~1.02
- Optional `zoom: 1.2` on rail only (composition scale, not redesign)
- will-change limited to sheet transform/opacity
