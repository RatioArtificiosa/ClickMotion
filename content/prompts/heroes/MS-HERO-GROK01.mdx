## Motion Specification

**Mode:** Scroll-as-narrative · **pin-until-complete** (**No Scroller**) · **PSAVE** (Perfect Scroll Video Engine). **Dual process.** Scroll sets a destination on `12` viewports. Down plays the film forward at **1.2x**. Up plays it backward at the same **1.2x**, **exactly one 3-frame step per seek**. Never jump a frame. **When they lift, leftover dest plus a 0.55s dest floor keeps the film going a little**, then rate eases to a stop. HUD CSS loops (sheen 12.5s, ice trip, marquee, orb spin, live dots) **keep running**. Release only when the **picture** arrives at `0` (up) or `1` (down). **Do not** autoplay-loop as primary. **Do not** seek `currentTime` across a jump.

**Hard ban:** tall multi-vh document scrollbar track.
**Hard ban:** seeking the playhead to a far destination (`video.currentTime = dest * duration` on a large delta).
**Hard ban:** a 3.6 aim track on this 62.5s film (two flicks dump dest). Locked earn is **12**.
**Hard ban:** pausing HUD loops when the film chases.
**Hard ban:** a low-res frame buffer or canvas overlay for reverse. Reverse walks the live video.
**Hard ban:** releasing the pin because the destination hit 1 while the picture is still walking.
**Hard ban:** a window wheel listener that keeps driving the film after the pin has released.
**Hard ban:** a replacement film with one I-frame (or long GOP + B-frames). Reverse will stall mid-film.
**Hard ban:** pausing on the last wheel tick. The stop is friction, then a graceful slowdown.
**Hard ban:** installing `gsap` or importing `ScrollTrigger`.

```
const VIRTUAL_VIEWPORTS = 12;  // GOLD: 62.5s even Sphere. Not Elyse/Vertex 3.6.
const PSAVE_RATE = 1.2;        // film-seconds per wall-second, both directions
const PSAVE_FRAME = 1 / 25;    // this film is 25fps
const PSAVE_REV_STRIDE = 3;    // reverse: exactly 3 frames per seek (0.12s)
const PSAVE_LIVE_MS = 280;     // still scrolling if last up/down is inside this window
const PSAVE_COAST_SEC = 0.55;  // leftover dest floor after last real intent
const PSAVE_EASE_SEC = 0.55;   // forward rate tapers over last leftover film-seconds
const PSAVE_FLIP_DEADZONE_PX = 32; // ignore tiny opposite trackpad ticks
```

**Earn vs perceived time:** this film is **even** Sphere time (the night-city show runs the whole 62.5s, not a late kick). Even films that are **short** (Elyse 10s, Vertex 12s) lock at **3.6**. This film is **long**. Two 1800px flicks on 3.6 dump dest past the last beat. On **12**, those same flicks aim about one third of the film. The visitor earns the Sphere. Do not copy Elyse 3.6. Do not flatten the edit.

**The lift:** leftover dest is the Elyse stop. On this 62.5s film dest still dies (1.2x eats it; a tiny opposite tick snaps dest). After last real intent, dest must sit at least `0.55s` of film ahead. Ignore opposite ticks under `32px`. Forward `playbackRate` stays 1.2 until leftover dest is under `0.55s`, then tapers toward ~0.42. Friction, then a graceful stop. Live window is **280ms**.

**Rebuild algorithm (mandatory):** one `100dvh` stage in **normal document flow**. There is **no** required next-sibling band inside this product. Do not `overflow: hidden` the page (a host embed must be able to scroll after release). Do not import ScrollTrigger or GSAP. Do not use `position: sticky`. Do not build a tall spacer. Gestures map **1:1** onto `12` viewports and only move the **destination**. First **real** opposite gesture snaps destination to the picture. Ignore tiny opposite ticks. Each frame, walk the picture toward that destination at **1.2x**, never more than **1/25s** of film on a forward fallback tick. **Down:** muted `play()` at `playbackRate 1.2`, ease over the last `0.55s` of leftover dest. After they lift, apply the `0.55s` dest floor once if dest is closer than that. **Up:** first real up-scroll cancels a pending forward destination. Walk `currentTime` backward exactly one 3-frame step per seek, **during the gesture and after**. Wait `seeked`. Never seek to the stop point. No loop. No low-res buffer. Release only when the **picture** is at `0+up` / `1+down`. Test live `currentTime` as well as the playhead ref (settle can stop ~1 frame short). After release the **page** owns scroll until the stage docks at the top (`top >= -2`). **Opening frame:** film starts black. Show a Scroll badge. Hide it **5 seconds after the first real scroll**. Reduced motion keeps the poster and static HUD.

| Element | Motion |
|---------|--------|
| Film | PSAVE: play toward destination forward or reverse, never jump a frame |
| Stage | Pinned 100dvh; no tall page track |
| Wheel | 1:1 onto the 12 aim track (destination only) |
| Lift | 0.55s dest floor + rate ease. Friction, then a graceful stop. |
| HUD | Sheen 12.5s, ice trip, marquee, orb, live dots keep looping |
| Scroll badge | Visible on black open. Hide 5s after first real scroll |
| Reduced motion | 100dvh static stage, poster + HUD, no PSAVE |

Capture helper: `window.__msScrollNarrative = { setProgress, getProgress, getTarget, pageOwns, productId: "MS-HERO-GROK01" }`. `getProgress` is the picture. `getTarget` is leftover dest. Root marker: `data-grokbot-drive="psave"`. After release: `data-grokbot-owns="page"`.
