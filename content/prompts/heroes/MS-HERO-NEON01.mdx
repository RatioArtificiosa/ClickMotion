## Design System

**Aesthetic Direction:** **NEON FORGE** - AAA game development studio. Pure black canvas, electric cyan `#00F0FF`, hot pink `#FF006E`, Space Grotesk display, Inter UI. Full-viewport rain-city film, liquid-glass nav, glitch H1 on load. Feels like a studio launch film under precise type - not a purple SaaS kit, not anime, not cheap stock cyberpunk.

**Famous-UI craft direction (not a clone):** High-end studio event page restraint (trailer calm + one signature motion) meets left-weighted editorial lockups. One video system. One glitch moment. Stop.

**Typography:**
- Display / H1: Space Grotesk 800-900, tracking `-0.04em`, line-height `0.85-0.9`, size `clamp(2.75rem, 8vw, 7.5rem)`
- Sub lockup: Space Grotesk, pink, slightly smaller clamp, slight negative margin under H1
- Body: Inter 300-400, 15-17px, line-height 1.65, white at ~65%
- Badge / nav: Inter 10-12px, uppercase tracking `0.16-0.22em` on badge

**Color tokens:**
| Token | Value |
|-------|--------|
| Canvas | `#000000` |
| Cyan | `#00F0FF` |
| Pink | `#FF006E` |
| White | `#FFFFFF` |
| Muted | `rgba(255,255,255,0.65)` |
| Glass | `rgba(255,255,255,0.04)` + blur |
| Scrim | left-heavy black gradients (see Layout) |

**Radius:** `rounded-full` on pills (intentional for this brand).  
**Spacing:** 8px grid. Safe horizontal inset minimum `px-8` / prefer `md:px-12` `lg:px-16`.

**Anti-slop hard ban:** purple mesh/aurora UI fills, shiny gradient text, emoji, marquee, bento clutter, border-beam kits, wellness cream, brutalist zero-radius system (Vertex), Meridian gold estate language.

**Differentiation:**
| vs | Neon Forge must not become |
|----|----------------------------|
| Meridian | Gold coast luxury scroll chapters |
| Vertex | Monochrome asteroid scroll-scrub |
| Aether | Cream wellness ocean |

## Motion Specification

**Mode honesty:** `video-background` + entrance glitch + desktop parallax. **Not** scroll-scrub chapters.

**Framer (if not reduced motion):**
- Badge: y -16→0, 0.55s  
- H1: y 36→0, 0.75s, delay 0.18s, then glitch (~3 micro jitters)  
- H2: y 36→0, delay 0.28s  
- Body: y 24→0, delay 0.38s  
- CTAs: y 16→0, delay 0.48s  
- Ease: `[0.25, 0.46, 0.45, 0.94]`

**Glitch (H1):** opacity / x / optional 1px blur pulses, settle clean.

**GSAP:** video wrapper scale 1→1.06, ScrollTrigger scrub 1.2, desktop only.

**Reduced motion:** fade only; no glitch; no parallax.
