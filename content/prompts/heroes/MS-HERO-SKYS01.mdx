## Motion Specification

**Mode:** Scroll-as-narrative · **pin-until-complete** (**No Scroller**) · **PSAVE** (Perfect Scroll Video Engine). **Dual process.** Scroll sets a destination on `12` viewports. Down plays the film forward at **1.2x**. Up plays it backward at the same **1.2x**, **exactly one 3-frame step per seek**. Never jump a frame. **When they lift, leftover dest plus a 0.55s dest floor keeps the film going a little**, then rate eases to a stop. HUD loops **keep running**. Release only when the **picture** arrives at `0` (up) or `1` (down).

```
const VIRTUAL_VIEWPORTS = 12;  // GOLD: 25.04s even sunrise. Not Elyse 3.6.
const PSAVE_RATE = 1.2;
const PSAVE_FRAME = 1 / 24;    // this film is 24fps
const PSAVE_REV_STRIDE = 3;
const PSAVE_LIVE_MS = 280;
const PSAVE_COAST_SEC = 0.55;
const PSAVE_EASE_SEC = 0.55;
const PSAVE_FLIP_DEADZONE_PX = 32;
```

**HUD clocks (independent of PSAVE, do not desync):**

| Clock | Period |
|-------|--------|
| CTA | 12.5s (scale 0-2s, gold trip ~5-11.5s, fade 880-890) |
| Dock sheen | 6.4s LTR |
| Dock gold trip | 12s (one lap, wait, loop) |
| Stats list | 10s then gauge |
| Rings | 2.8s |
| CDMX clock | 15s |
| Video | 25.04s PSAVE (not synced to CTA, residual SS-01) |

**Hard ban:** tall multi-vh track. Seeking `currentTime` across a jump. A 3.6 aim track on this 25s film. Pausing HUD loops. Installing gsap. Restoring filament.

### Two clocks

| Clock | Who writes it | Who reads it |
|-------|----------------|--------------|
| Destination 0-1 | Gestures, 1:1 on the 12 vh track | Chase loop only |
| Playhead 0-1 | Decoded picture (`currentTime / duration`) | Release only |

The destination may leap. The picture may not. HUD loops do not follow either clock.

### Rebuild algorithm

1. Render one `100dvh` stage in normal document flow. Do not `overflow: hidden` the page. Do not use `position: sticky`. Do not build a tall spacer.
2. Gestures add `deltaPx / (12 * innerHeight)` to destination only. Raw 1:1.
3. Wheel (`passive: false`): ignore ctrl/meta zoom; normalize `deltaMode`; `preventDefault` only while the pin owns.
4. **Down:** muted `play()` at 1.2. After lift, leftover dest plus 0.55s dest floor. Ease over last leftover dest.
5. **Up:** first real opposite gesture snaps dest onto the picture. Reverse every 3rd frame. Wait `seeked`.
6. HUD loops keep running. Do not pause them.
7. Release only when the picture is at 0+up or 1+down. Then page owns until dock (`top >= -2`).
8. Reduced motion: poster + static HUD. No chase.

Capture helper: `window.__msScrollNarrative = { setProgress, getProgress, getTarget, pageOwns, productId: "MS-HERO-SKYS01" }`. Root: `data-skyspires-drive="psave"`. After release: `data-skyspires-owns="page"`.
