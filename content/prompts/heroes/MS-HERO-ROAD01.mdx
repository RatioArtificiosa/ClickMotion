## Promise (buyer-facing)

**Roadster** is a **studio-drive hero** for luxury vehicle and product launches. A high-key film loops forever. Scroll aims sparse product cards with enter, hold, and exit. At the end, a black rounded sheet pulls up over the film with official-style specs, a spinning GLB turntable, and reserve CTAs.

**No Scroller (pin-until-complete).** Scroll aims virtual progress on **13.3 viewports** (12 for the cards, 1.3 for the sheet). The page does not physically scroll during the viewing. When the journey ends, the pin **releases**. Then the **page owns the wheel** until the stage docks at the top of the viewport again. Pointer on the next sibling never drives the hero. Not a tall sticky track. Not GSAP ScrollTrigger pin. Not Lenis. Not PSAVE. The film free-plays. Scroll never seeks `currentTime`.

**How you build it:** download the product pack. Tell your AI: *Build Roadster using the files in this folder. Read PROMPT.md. Prefer source/TeslaRoadsterPromo.tsx. No Scroller: pin-until-complete. One 100dvh stage. Scroll aims virtual progress on 13.3 viewports. At 0 plus up, or 1 plus down, release. After release at the end, the page owns until dock (top >= 0; implement >= -2). Do not install gsap or lenis. Do not build a tall multi-vh sticky track. Do not add PSAVE. Never map scroll to video.currentTime.*

**Why use it:**
- Hybrid motion avoids expensive video scrub and keeps GPU calm
- Catalog-bright film stays pure; type is dark ink with local lift only
- Specs sheet + 3D close the story without a flat footer band
- Every brand mark, card, spec, film, and model is meant to be restaged

Default demo content (TESLA / ROADSTER, EV supercar claims) is only a starting board. Tell your AI to restage everything until it reads as you alone.

## Design System

**Aesthetic Direction:** high-key automotive studio, dark ink type on bright film, pure black specs sheet, massive product name, giant performance numbers, restrained red accent on progress tip only.

**Craft direction:** vehicle unveil x catalog stills x product-page density. Calm until scroll arrives, then deliberate card pacing and a satisfying sheet pull-up.

**Do not:**
- Scroll-scrub the film (`currentTime` mapping)
- Grey-wash or vignette the entire frame
- Use frosted glass story cards
- Ship storefront preview videos as rebuild media
- Install gsap, ScrollTrigger, or lenis
- Mount WebGL while the sheet is fully off-screen (context thrash)

**Differentiation:**

## Motion Specification

**Mode:** **No Scroller** = **pin-until-complete** + loop film + enter-hold-exit cards + sheet pull-up + Y-spin GLB. Not video scrub. Not PSAVE.

```
Earn: VIRTUAL_VIEWPORTS = 13.3
virtualDistance = 13.3 * window.innerHeight
delta progress = wheelDeltaY / virtualDistance
```

| Event | Timing | Ease / notes |
|-------|--------|--------------|
| Intro | g near 0 | Film only; Scroll cue until first card |
| Cards | first ~90% of g | Enter ramp, hold full opacity, exit ramp |
| **Pin freeing** | after g = 1 + down | **page owns** until dock (`top >= -2`) |
| Sheet | last ~10% of g | `translateY(100%)` to `0` over live film |
| 3D | while sheet > ~20% | Continuous Y spin; Canvas unmounts off-screen |
| Reduced motion | on load | Settled readable cards/sheet; spin paused |

**3D hardening (required):** preload GLB; no placeholder flash; no HDR Environment fetch; light dpr; `Clone` for safe remount; context-loss recovery; dispose Canvas when sheet off-screen.

## Technical implementation notes for AI tools

Build a single default-export React component `TeslaRoadsterPromo` (or page section).

Stack: React + TypeScript. No gsap. No ScrollTrigger. No Lenis. three + @react-three/fiber + @react-three/drei for the turntable.

Root marker: `data-roadster-drive="pin"` · `data-product="MS-HERO-ROAD01"`. After release: `data-roadster-owns="page"`. Capture helper: `window.__msScrollNarrative`.

Film: muted autoPlay loop playsInline. Never seek.

`prefers-reduced-motion`: settled cards, docked sheet, spin paused.

- GLB: prefer 50k to 200k tris for web
