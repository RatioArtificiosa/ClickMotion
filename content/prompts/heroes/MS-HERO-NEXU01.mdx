## Design System

**Aesthetic Direction:** **NEXUS AI** - enterprise intelligence layer hero. One full-bleed **uncut** neural lattice film free-plays under restrained cyan/magenta chrome. Signature: left **decision path rail** (Sense → Route → Compound) with a light that travels the line, fills each node on contact, then the next word in the headline melts letter-by-letter. Space Grotesk display + Inter. Stage ink `#07080F`, cool type `#E8F0FF`, cyan `#00D4FF`, magenta `#FF006E`. Institutional density. Not liquid-glass kitsch. Not purple mesh SaaS. No scroll scrub.

**Famous-UI craft direction (not a clone):** Anthropic/OpenAI launch restraint × institutional product density × neural void cinema. Calm authority. Not Motionsites pill docks. Not Apex quantum lab chrome. Not Neon rain city.

**Typography:**
- Brand wordmark: Space Grotesk / Inter, tracking wide, weight 600-700, uppercase + small "AI" accent
- Kicker: Inter 10px, tracking `0.18em`, uppercase, cool mist + cyan mono id `NX / 01`
- H1 main: Space Grotesk, `clamp(2.75rem, 7.4vw, 5.6rem)`, weight 600, tracking `-0.045em`, line-height 0.96, cool white
- H1 sub: same family lighter weight, `clamp(2.15rem, 5.6vw, 4.15rem)`, "That " static + rotating verb with period attached to the word
- Lead: Inter 300, `clamp(0.98rem, 1.15vw, 1.08rem)`, line-height 1.7, max-width ~30rem, mist
- Path labels: mono micro steps; display names; soft notes
- CTA primary: solid cool type on soft fill / border cyan rim optional
- System tape: mono keys + values, live pulse

**Color tokens:**
| Token | Value |
|-------|--------|

## Layout Structure

- **Hero:** full-viewport stage (`100vh` / `100dvh`, min-height ~700px), overflow hidden
- **Film:** full bleed `object-fit: cover`, `object-position: ~58% center`, scale ~1.015
- **Veil + vignette:** soft edge gradients; film remains readable
- **Nav:** absolute top - brand left, links center (desktop), docs + primary CTA right
- **Signature path rail (desktop ≥960px):** left column - Path label, vertical line, three nodes (Sense / Route / Compound), travel pulse
- **Copy lockup:** center-left - kicker, H1 (Intelligence. / That [verb].), lead, CTA row
- **Constellation plate (wide desktop):** floating film-field label (Active graph)
- **System tape footer:** live pulse + GRAPH / NODES / ROUTES / EVAL / REGION
- **Safe insets:** horizontal clamp; type never flush to edge

## Motion Specification

**Mode:** Free-playing full film (`autoPlay muted loop playsInline`). **Not** video scrub. Scroll does **not** map to `video.currentTime`. Optional subtle scale scrub on the video wrap only (atmosphere).

| Element | Motion |
|---------|--------|
| Film | Continuous loop of complete neural lattice run; IntersectionObserver pause offscreen |
| Path travel | Light pulse rides the vertical line (centered); small between nodes, larger on hit; z above bullets |
| Path nodes | Each bullet fills/brightens only when the pulse arrives (synced linear cycle) |
| Headline cycle | Sequential: word A letters melt out (random per letter) → fully gone → word B letters melt in (random). Period is part of each word. Hold ~3s sharp. |
| Copy entrance | Soft fade + Y on load (Framer Motion); respect reduced motion |
| Reduced motion | Static poster, no autoplay required, first cycle word only, path static |
