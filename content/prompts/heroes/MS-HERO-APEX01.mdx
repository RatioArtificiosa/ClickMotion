## Design System

**Aesthetic Direction:** **APEX QUANTUM** - deep-tech quantum computing platform. Void indigo canvas `#070A1A`, electric quantum cyan `#00D4FF`, controlled violet `#A855F7`, ice headlines `#E8F0FF`. JetBrains Mono display + Inter UI. Full-viewport cryogenic lab film, cold cyan glass nav, precise unhurried entrances. Feels like serious quantum hardware craft - not neon rain megacity, not purple mesh SaaS kits, not wellness cream, not forest climate, not film-lot amber, not brutalist security scrub.

**Famous-UI craft direction (not a clone):** Quantum hardware launch restraint (IBM Quantum / Rigetti calm + product precision). One video system. Soft entrances. Stop.

**Typography:**
- Display / H1: JetBrains Mono 600-700, tracking `-0.04em`, line-height `0.9`, size `clamp(2.75rem, 8vw, 7rem)`
- Body: Inter 300-400, 15-17px, line-height 1.65, ice at ~65%
- Badge / nav: Inter 10-12px, uppercase tracking `0.16-0.22em` on badge

**Color tokens:**
| Token | Value |
|-------|--------|
| Canvas | `#070A1A` |
| Cyan | `#00D4FF` |
| Violet | `#A855F7` |
| Ice | `#E8F0FF` |
| Muted | `rgba(232,240,255,0.65)` |
| Glass | cyan-tinted blur |
| Scrim | left-heavy void indigo gradients |

**Radius:** `rounded-full` on pills.  
**Spacing:** 8px grid. Safe horizontal inset minimum `px-8`.

**Anti-slop hard ban:** pink neon rain kits, purple mesh aurora wallpaper, shiny gradient text, emoji, Aether cream wellness, Lumina film-lot amber, Terra forest sage, Meridian multi-chapter scrub, Vertex zero-radius mono, Neon glitch city.

| Terra | Forest sage climate aerial |
