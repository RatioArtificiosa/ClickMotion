## Design System

**Aesthetic Direction:** **SABLE** (Maison Sable) - private-house holiday fashion hero. One full-bleed **uncut** winter village walk film. The subject is the product. Type is sparse, quiet, and expensive. Champagne gold on ivory over dark edge veils. No pill nav. No glass card stacks. No mid-frame marketing essays. Forbes-tier restraint: the film carries the emotion; the UI frames it.

**Famous-UI craft direction (not a clone):** The Row / Toteme holiday film discipline × private bank type density × editorial letterbox pacing. Light never kitsch. Holiday without Santa or glitter UI.

**Typography:**
- Brand / wordmark: Cormorant Garamond (or high-end transitional serif), 0.95rem, tracking `0.42em`, uppercase, gold period
- Season label: Inter 10px, tracking `0.32em`, gold `#C4A574`
- House line: Cormorant 0.95-1.15rem, tracking `0.08em`, ivory 72%
- Progress note: Inter 10px, tracking `0.06em`, ivory 38%
- CTA: Inter 0.72rem, tracking `0.18em`, uppercase, ink on ivory gradient
- Nav links: Inter 0.68rem, tracking `0.2em`, uppercase, mist ivory

**Color tokens:**
| Token | Value |
|-------|--------|
| Stage ink | `#0C0B0A` |
| Ivory | `#F7F3EC` / `#FAF7F1` |
| Champagne gold | `#C4A574` |
| Warm highlight | `#E8D5B0` |
| CTA fill | `#F4EFE4` → `#E8DCC8` |
| Veil | soft charcoal edges only, center clear |

**Anti-slop hard ban:** purple mesh, neon pills, emoji, rainbow type, "AI fashion" glitter, scroll-scrubbing the film, mid-screen multi-paragraph sales copy, Atelier as a default word, Motionsites liquid-glass docks, dense metric cards on the film face.

**Differentiation:**
| vs | Sable must not become |
|----|------------------------|
| Revel | Rose-gold phone-break scroll scrub |
| Mirage | Desert agency glass cards |
| Lumina | Film-lot amber production hero |
| Meridian | Multi-chapter coastal estate scrub |

## Layout Structure

- **Hero:** sticky full-viewport stage inside a short scroll track (~180vh) for pin atmosphere only
- **Film:** full bleed `object-fit: cover`, `object-position: center 42%`, scale ~1.01
- **Nav:** absolute top, three-column grid: brand left, links center, private-view CTA right
- **Intro lockup:** top-left season + house line (stays quiet; never competes with the face)
- **Center:** intentionally empty - subject walks free
- **Footer chrome:** Maison Sable label + true film time, hairline gold progress (video clock), holiday line, fixed "Holiday · Private collection", ivory CTA
- **Safe insets:** horizontal `clamp(1.35rem, 4.5vw, 3.5rem)`; type never flush to edge; soft vignette only

## Motion Specification

**Mode:** Free-playing full film (autoPlay muted loop playsInline). **Not** video scrub. Scroll does **not** map to `video.currentTime`.

| Element | Motion |
|---------|--------|
| Film | Continuous loop of complete walk; progress bar = `currentTime / duration` |
| Stage | Sticky pin for ~180vh track |
| Intro | Optional 8px Y drift on scroll (atmosphere only) |
| CTA hover | translateY -1px, soft shadow deepen, arrow +3px |
| Nav links | color to gold 350ms |
| Reduced motion | static still fallback, no autoplay required, auto height stage |

Scrub intensity: none on film. UI motion subtle only.

## Accessibility

- `prefers-reduced-motion` static path
- Semantic `section` / `nav` / `footer`
- Decorative film layers `aria-hidden`
- Focusable text links and CTA
- Contrast: ivory on dark veil; gold accents for labels

## Performance Notes

- Single video element, cover scale 1.01
- Animate transform/opacity only on UI
- No mid-frame glass blur stack (keeps GPU light)
- Progress bar updates on `timeupdate` only
- font-display: swap
