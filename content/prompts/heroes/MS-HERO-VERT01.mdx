## Promise (buyer-facing)

**VERTEX SECURITY** is an enterprise cybersecurity **pin-until-complete** scroll hero: one full-viewport black stage, a 12-second monochrome asteroid / wireframe globe film the playhead walks through three chapters that harden from zero-trust to prevention. **PSAVE** (Perfect Scroll Video Engine): scroll aims, down plays forward, up plays reverse, the picture never jumps a frame. Not a tall multi-page scrollbar track. Not Meridian dark coastal. Not Revel pearl fashion.

## Motion Specification

**Mode:** Scroll-as-narrative · **pin-until-complete** · **PSAVE** (Perfect Scroll Video Engine). Scroll sets a destination on `3.6` viewports. Down plays the film forward at **1.2x**. Up plays it backward at the same **1.2x**, **exactly one 3-frame step per seek**. Never jump a frame. **When they lift, leftover dest plus a 0.55s dest floor keeps the film going a little**, then rate eases to a stop. **Do not** autoplay-loop as primary. **Do not** seek `currentTime` across a jump.

**Hard ban:** tall multi-vh document scrollbar track (legacy `420vh` sticky pattern).  
**Hard ban:** seeking the playhead to a far destination (GSAP scrub, old Vertex wheel-gain `0.22`, old scrub lag `0.45`).  
**Hard ban:** mapping raw wheel `deltaY` through a gain, or restoring `VIRTUAL_VIEWPORTS = 3.2`. Locked earn is **3.6**.  
**Hard ban:** a Revel `12` aim track on this even asteroid film (there is no halfway kick to earn).  
**Hard ban:** a low-res frame buffer or canvas overlay for reverse. Reverse walks the live video.  
**Hard ban:** releasing the pin because the destination hit 1 while the picture is still walking.  
**Hard ban:** a replacement film with one I-frame (or long GOP + B-frames). Reverse will stall mid-film.  
**Hard ban:** pausing on the last wheel tick. The stop is friction, then a graceful slowdown.  
**Hard ban:** a closing footer / membership / atelier band.

```
const VIRTUAL_VIEWPORTS = 3.6; // GOLD: even asteroid approach. Not old 3.2 seek-scrub. Not Revel 12.
const PSAVE_RATE = 1.2;        // film-seconds per wall-second, both directions
const PSAVE_FRAME = 1 / 24;    // never skip more than one frame in a forward tick
const PSAVE_REV_STRIDE = 3;    // reverse: exactly 3 frames per seek (0.125s)
const PSAVE_LIVE_MS = 220;     // still scrolling if last up/down is inside this window
const PSAVE_COAST_SEC = 0.55;  // leftover dest floor after last real intent
const PSAVE_EASE_SEC = 0.55;   // forward rate tapers over last leftover film-seconds
const PSAVE_FLIP_DEADZONE_PX = 32; // ignore tiny opposite trackpad ticks
```

**Perceived time:** this film is even. Rocks shed toward the viewpoint the whole 12 seconds. It is not Revel slow-then-kick. The **3.6** track is locked because the story is a steady approach, like Elyse sanctuary time. Do not raise it to 12. Do not restore 3.2 + wheel gain.

**The lift:** leftover dest is the Elyse stop. On this 12s film dest still dies (1.2x eats it; a tiny opposite tick snaps dest). After last real intent, dest must sit at least `0.55s` of film ahead. Ignore opposite ticks under `32px`. Forward `playbackRate` stays 1.2 until leftover dest is under `0.55s`, then tapers toward ~0.42. Friction, then a graceful stop. This `0.55` is **not** old GSAP `SCRUB_LAG 0.45`.

**Rebuild algorithm (mandatory):** one `100dvh` stage in **normal document flow**. There is **no** next-sibling band inside this product. Do not `overflow: hidden` the page (a host embed must be able to scroll after release). Do not import ScrollTrigger or GSAP. Do not use `position: sticky`. Do not build a `420vh` spacer. Gestures map **1:1** onto `3.6` viewports and only move the **destination**. First **real** opposite gesture snaps destination to the picture. Ignore tiny opposite ticks. Each frame, walk the picture toward that destination at **1.2x**, never more than **1/24s** of film on a forward fallback tick. **Down:** muted `play()` at `playbackRate 1.2`, ease over the last `0.55s` of leftover dest. After they lift, apply the `0.55s` dest floor once if dest is closer than that. **Up:** first real up-scroll cancels a pending forward destination. Walk `currentTime` backward exactly one 3-frame step per seek, **during the gesture and after**. Wait `seeked`. Never seek to the stop point. No loop. No low-res buffer. Copy, chapters, and the white bar follow the **playhead**. Release only when the **picture** is at `0+up` / `1+down`. Test live `currentTime` as well as the playhead ref (settle can stop ~1 frame short). After release the **page** owns scroll until the stage docks at the top. **Opening frame:** the poster is the opening asteroid (≈ frame 0). Kick-seek `0.04 → 0`, wait `seeked`, fade the film in (`.is-ready`). Reduced motion may keep that poster and show chapter 01 only.

| Element | Motion |
|---------|--------|
| Film | PSAVE: play toward destination forward or reverse, never jump a frame |
| Stage | Pinned 100dvh; no tall page track |
| Wheel | 1:1 onto the 3.6 aim track (destination only) |
| Lift | 0.55s dest floor + rate ease. Friction, then a graceful stop. |
| Chapters | Crossfade eyebrow/title/body from **playhead** (vertexFade / vertexRise) |
| Progress bar | `scaleX(playhead)` white hairline, origin left |
| Scroll cue | visible only when playhead &lt; 0.04 |
| Reduced motion | 100dvh static stage, poster + chapter 01, no PSAVE |

Capture helper: `window.__msScrollNarrative = { setProgress, getProgress, getTarget, productId: "MS-HERO-VERT01" }`. `getProgress` is the picture. `getTarget` is leftover dest.
