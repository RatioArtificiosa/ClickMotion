## Design System

**Aesthetic Direction:** **VERTEX SECURITY** - enterprise cybersecurity, monochrome brutalist. Black canvas, pure white type, Space Grotesk display, Inter UI. Wireframe globe video scrubbed by scroll. Feels like a serious SOC vendor, not a SaaS startup kit.

**Famous-UI craft direction (not a clone):** Linear / Stripe enterprise density meets brutalist editorial (no soft glass pills as house chrome). One video system + sharp geometry + scroll-as-narrative chapters.

**Typography:**
- Display: Space Grotesk 700 for chapter titles
- Chapter 1 H1: `SECURITY.` white, `clamp(2.35rem, 6vw, 5.5rem)`, leading 0.92, tracking -0.04em
- Sub: `WITHOUT COMPROMISE.` white/70, smaller clamp
- Body: Inter 400, 15-17px, white/65, max-width ~36rem
- Nav / labels: 10-11px uppercase tracking 0.16-0.28em

**Colors:**
| Token | Value |
|-------|--------|
| canvas | `#000000` |
| text | `#FFFFFF` |
| muted | white at 40-65% |
| CTA primary | white fill, black text |
| CTA secondary | white border outline |
| scrim | left-heavy black gradient |

**Radius:** **0** on CTAs and chrome (brutalist - no rounded-full pills).  
**Anti-slop hard ban:** cyan/pink neon kit tokens, aurora mesh, border-beam, shiny text, glass pill dock nav, Magic UI default stacks.

**Safe margins (critical):** Horizontal padding `px-10` to `lg:px-20`. All type and CTAs `shrink-0` / `whitespace-nowrap` where needed. Keep primary copy inside an inner max-width so gallery `object-cover` crop never clips letters.

## Layout Structure

```
[Scroll track ~420vh - NO footer after]
  [Sticky 100vh stage]
    video cover (globe) - currentTime = scroll progress * duration
    dual scrim (diagonal + vertical)
    fixed-feel nav + progress hairline
    chapter stack: eyebrow, title, body, (final: dual CTAs + 3 stats)
    chapter index 01/02/03 right rail
    scroll cue at start
```

**Do not add a closing membership / footer band.** The narrative ends when the pin track ends.

**Scrim:**
```
linear-gradient(105deg, rgba(0,0,0,0.86) 0%, rgba(0,0,0,0.58) 42%, rgba(0,0,0,0.38) 100%)
+ linear-gradient(180deg, rgba(0,0,0,0.5) 0%, transparent 28%, rgba(0,0,0,0.58) 100%)
```

## Motion Specification

```ts
// GSAP ScrollTrigger on pin track
// start: top top, end: bottom bottom, scrub: 0.45
// onUpdate: video.currentTime = progress * duration
// Chapter crossfade via key remount + CSS keyframes (vertexFade / vertexRise)
// reduced-motion: 100vh static, no scrub, chapter 1 only
```

No magnetic cursor. No 3D library - video only. No autoplay loop - scroll owns time.
