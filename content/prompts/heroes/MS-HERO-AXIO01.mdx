## Design System

**Aesthetic Direction:** **AXIOM** - institutional fintech inverted-markets hero. One full-bleed **uncut** inverted NYC golden-hour street film free-plays under private-bank chrome. Signature: a fixed level gold **TRUE NORTH** horizon hairline that never tilts while the city inverts. Serif display + Inter. Champagne gold on cool ivory over deep stage ink. Order when markets flip. No neon crypto kitsch. No scroll scrub.

**Famous-UI craft direction (not a clone):** Private bank product film discipline x Stripe/Bloomberg institutional density x editorial letterbox pacing. Calm authority. Not Motionsites glass docks. Not purple mesh SaaS.

**Typography:**
- Brand / wordmark: Inter 0.78rem, tracking `0.38em`, weight 700, uppercase
- Kicker: Inter 10px, tracking `0.28em`, gold `#D4AF6A`
- H1 display: Instrument Serif (or high-end transitional serif), `clamp(2.35rem, 5vw, 3.85rem)`, line-height 1.05, tracking `-0.03em`, three stacked lines; third line italic cream `#F0E6D0`
- Lead: Inter 0.92-1.05rem, line-height 1.55, max-width **56ch**, **exactly two lines** (sentence 1 alone; sentences 2-3 on line 2)
- Proof values: Instrument Serif ~1.25rem, tabular nums
- Proof labels: Inter 9px, tracking `0.14em`, uppercase
- Progress note: Inter ~10px, tracking soft, cool mist
- CTA: Inter 0.72rem, tracking `0.16em`, uppercase, ink on ivory gradient
- Horizon badge: Inter 9px, tracking `0.24em`, uppercase

**Color tokens:**
| Token | Value |
|-------|--------|
| Stage ink | `#07090F` |
| Cool ivory | `#EEF2F7` / `#F4F7FB` |
| Champagne gold | `#D4AF6A` |
| Cream accent | `#F0E6D0` |
| Veil | deep ink left/right/bottom; center film readable |
| Proof glass | `rgba(10,14,22,0.48)` + gold 0.5px rim |

**Anti-slop hard ban:** purple mesh, neon crypto chrome, emoji, rainbow type, Motionsites pill docks, scroll-scrubbing the film, mid-frame multi-paragraph sales essays, "demo only" / "scaffold" / "uncut film" product notes in UI, opaque black slabs instead of soft veil.

**Differentiation:**
| vs | Axiom must not become |
|----|------------------------|
| Orbit | Generic neobank amber card grid |
| Meridian | Multi-chapter coastal estate scrub |
| Mirage | Desert agency glass pivot cards |
| Sable | Sparse holiday fashion walk (no proofs / no horizon) |
| Apex | Quantum cyan lab void |

## Layout Structure

- **Hero:** sticky full-viewport stage inside a short scroll track (~175vh) for pin atmosphere only
- **Film:** full bleed `object-fit: cover`, `object-position: center`, scale ~1.02
- **Signature horizon:** absolute level gold hairline at ~48% height + "True north" badge left - never rotates with the film
- **Nav:** absolute top, three-column grid: brand left, links center, Request access right (underline gold)
- **Copy lockup:** lower-left - kicker, three-line H1, two-line lead, three proof chips
- **Footer chrome:** Axiom label + true film time, hairline gold progress (video clock), calm line, "Order in inverted markets", ivory CTA
- **Safe insets:** horizontal `clamp(1.35rem, 4.5vw, 3.5rem)`; type never flush to edge; soft vignette only

## Motion Specification

**Mode:** Free-playing full film (`autoPlay muted loop playsInline`). **Not** video scrub. Scroll does **not** map to `video.currentTime`.

| Element | Motion |
|---------|--------|
| Film | Continuous loop of complete inverted NYC run; progress bar = `currentTime / duration` |
| Stage | Sticky pin for ~175vh track |
| Copy | Optional ~14px Y drift + slight opacity on scroll (atmosphere only) |
| CTA hover | translateY -1px, soft shadow deepen, arrow +3px |
| Nav links | color to gold 300ms |
| Reduced motion | static still fallback, no autoplay required, auto height stage |

Scrub intensity: none on film. UI motion subtle only. Horizon never animates rotation.
