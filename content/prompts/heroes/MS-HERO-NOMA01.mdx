## Promise (buyer-facing)

**Nomad Travel** is a full-viewport **luxury travel platform hero**: warm espresso canvas, terracotta accent, cream editorial type, and a looping cinematic film of extraordinary empty places. Visitors feel private-club aspiration before the first booking form.

**Why use it:**
- Travel / hospitality brands that sell **stays**, not backpacks
- One film world + soft entrances - no multi-chapter scrub complexity
- Playfair + Inter system restages cleanly for any luxury stay brand
- Client HD is pure B-roll (no burnt UI); storefront dual previews are separate

Default copy (**Go beyond. / Stay forever.**) is a starting board. Restage destinations, stats, and CTAs until it is unmistakably yours.

**How you build it:** download the product pack (prompt + source + film). Tell your AI: *Build Nomad Travel using the files in this folder. Read PROMPT.md.*

## Design System

**Aesthetic Direction:** Premium editorial travel - espresso `#1C140A`, terracotta `#C17A4A`, cream `#FEF3C7`. Playfair Display headlines, Inter UI. Soft cream glass. Quiet proof stats. Aman × Condé Nast Traveler launch craft - **not** backpacker, neon, fintech chrome, or spa-white wellness.

**Famous-UI craft direction (not a clone):** Private travel club editorial calm + prestige resort brand-film pacing. One signature system: free-play film under warm type, never scroll-scrub chapters.

**Typography:**
- Display / H1: Playfair Display 500-700, tracking `-0.03em`, line-height `0.9`, size `clamp(3rem, 9vw, 7.5rem)`
- Accent line: same face, terracotta
- Body: Inter 300-400, 15-16px, line-height 1.7, cream at ~68%
- Badge / nav: Inter 10-12px, uppercase tracking on badge

**Color tokens:**

| Token | Value |
|-------|--------|
| Canvas | `#1C140A` |
| Cream | `#FEF3C7` |
| Terracotta | `#C17A4A` |
| Glass | cream 8% + blur 48px |

**Spacing:** 8px grid · content max ~44rem · full-bleed video · safe horizontal inset min ~2rem

**Anti-slop hard ban:** neon cyan/pink, purple mesh, pill glass SaaS dock as the only identity, grey full-frame wash, multi-chapter video scrub, backpacker hostel energy.

**Differentiation:**

| vs | Nomad must not become |
|----|------------------------|
| Meridian | Scroll-scrub multi-chapter estate film |
| Studio Sequence | World-scale camera pull-out billboard |
| Terra / Aether | Different palette and signature motion |
| Generic dark SaaS hero | Inter-only bold H1 + mesh + neon |

## Motion Specification

**Mode:** free-play film + entrance + desktop film parallax. **Not** scroll-scrub video.

| Layer | Spec |
|-------|------|
| Entrance | Framer staggered fade/up (badge → H1 → accent → body → CTAs → stats) |
| Ease | `[0.25, 0.46, 0.45, 0.94]` · ~0.75s with staggered delays |
| Parallax | GSAP: video wrap scale `1 → 1.06`, scrub `1.25`, desktop only (`start: top top` / `end: bottom top`) |
| Video time | **Never** scrub `video.currentTime` |
| Reduced motion | Opacity only; no parallax; hide scroll cue |
