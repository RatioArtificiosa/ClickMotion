## Design System

**Aesthetic Direction:** **REVEL** - fashion commerce scroll narrative. Pearl canvas `#F7F4F1`, charcoal ink `#1A1614`, rose gold `#C4A574`, soft blush `#E8B4B8`. Instrument Serif display + Inter UI. Sticky full-viewport stage; **scroll owns the film timeline** (scrub). Light studio luxury - not dark private-bank Meridian, not mono Vertex security, not neon cyberpunk, not forest climate, not quantum lab.

**Famous-UI craft direction (not a clone):** High-fashion campaign site restraint (Vogue digital calm × Apple product-film pacing). One film. Four chapters. Scroll owns time. Stop.

**Typography:**
- Display / H1: Instrument Serif, tracking `-0.03em`, line-height `0.98`, size `clamp(2.5rem, 6.4vw, 5.5rem)`
- Body: Inter 300-400, 15-17px, line-height 1.7
- Badge / nav: Inter 10-11px, uppercase tracking `0.18-0.28em`

**Color tokens:**
| Token | Value |
|-------|--------|
| Pearl | `#F7F4F1` |
| Ink | `#1A1614` |
| Rose gold | `#C4A574` |
| Blush | `#E8B4B8` |
| Cream on film | `#F7F4F1` with soft shadow |
| Progress | rose gold → blush → rose gold |

**Radius:** Fashion-sharp buttons (slight or zero). Thin progress line.  
**Spacing:** 8px grid. Safe horizontal inset minimum `px-8`.

**Anti-slop hard ban:** purple mesh, emoji, rainbow text, Meridian dark gold coastal clone, Vertex zero-radius mono, Neon rain city, glitch H1, host chrome.

**Differentiation:**
| vs | Revel must not become |
|----|------------------------|
| Meridian | Dark coastal multi-chapter gold estate |
| Vertex | Monochrome security scrub |
| Verve | Loud Gen-Z social purple/pink kitsch |
| Neon | Cyberpunk rain megacity |
| Apex | Quantum void cyan lab |

## Motion Specification

GSAP ScrollTrigger on pin track: `start: "top top"`, `end: "bottom bottom"`, `scrub: 0.5`.  
`video.currentTime = progress * duration` (threshold 16ms).  
Chapter text CSS fade/rise 0.65-0.85s on change.  
Progress bar `scaleX(progress)`.  
Scroll cue until progress > 0.05.  
**Reduced motion:** no scrub, static ~0.45 progress frame, single chapter view.
