## Promise (buyer-facing)

LEDGER is a mid-page **pricing section** that behaves like a private investment board, not a SaaS card row. Scroll pins the stage. Virtual progress writes the house: Studio, Firm, Seat, House. The recommended seat holds the largest type. Line items stamp onto a paper ledger. Visitors do not compare three equal tiles. They sit with one figure at a time.

**Why use it:**
- Your pricing feels like terms on letterhead, not a template grid
- Scroll owns the motion, so the section stays intentional under the user's hand
- Every name, figure, row, and CTA is meant to be replaced with your house system
- Drop-in section (not a full homepage), so it sits cleanly after a calm fintech hero
- Built for banks, desks, and operators who sell trust with paper and type

Default demo content (Ledger wordmark, seat schedule, clearing copy) is only a starting board. Tell your AI to restage everything until it reads as you alone.

## Design System

**Aesthetic Direction:** **LEDGER** - mid-page **pricing / investment board** (not a hero, not three cards). Warm paper stage `#EFE8DC`. Warm ink `#14110C`. Bronze `#7A6248` as hairline and recommended mark only. Giant italic serif names. Tabular serif figures. Mono labels. Radius 0.

**Famous-UI craft direction (not a clone):** financial print × Stripe restraint × Linear density. Boardroom paper. No glass. No mesh.

**Design language:** `calm-fintech`  
**Token theme:** `print-ledger`  
**Motion primitive:** `pin-until-complete` (virtual viewports **3.2**, spring lag ≈ Meridian **0.45**)

**Typography:**
- Display name: Instrument Serif italic, `clamp(2.4rem, 7vw, 5.25rem)`, tracking `-0.03em`, line-height `0.9`

- Body / period: Inter 13px, muted
- Labels / masthead / CTA: IBM Plex Mono, 10–11px, uppercase tracking `0.14–0.28em`

**Color tokens (defaults - replace freely):**

**Anti-slop hard ban:** purple mesh, indigo buttons, three equal rounded cards, toggle leftover, shiny H1, pill docks, aurora, number ticker as identity, glassmorphism as trust theater, Magic UI / v0 default pricing.

## Layout Structure

Pinned `100dvh` stage. Safe inset `px-8` / `md:px-14` / `lg:px-18`. Max width ~1180px.

1. Top bronze progress hairline (scaleX from virtual progress)
2. Masthead rule: LEDGER left, chapter meta right
3. Desktop left index (01 Studio … 04 House), clickable
4. Main plate: kicker, display name, figure, period
5. Horizontal ink rule
6. Definition-list ledger rows (label mono / value sans)
7. Foot: four plan names with small figures + solid ink CTA

No page scrollbar as the method. Wheel / trackpad / touch / arrows drive virtual progress 0→1. At 0 + scroll up, or 1 + scroll down, release so a host page can continue.

## Motion Specification

**Signature (one):** pin-until-complete

**Enter (support, once on view):** `stamp-settle` (elegant / letterpress). Duration 720ms, stagger 70ms, ease `[0.16, 1, 0.3, 1]`. Interaction (wheel, index, rail, CTA press) starts after land (~980ms). Reduced motion skips enter.

**Engine:** Motion (Framer lineage). `useMotionValue` + `useSpring` lag (stiffness 88, damping 28).

**Numbers:**
- Virtual effort: **3.2 viewports**
- Spring lag approximates scrub **0.45**
- Chapter windows: intro 0–0.10 · Studio 0.10–0.30 · Firm 0.30–0.50 · Seat 0.50–0.78 (longer dwell) · House 0.78–1
- Plate crossfade: 480ms, ease `[0.22, 1, 0.36, 1]`
- Rows stamp with chapter local progress after 0.22
- Capture API: `window.__msScrollNarrative` `{ setProgress, getProgress, productId: "MS-SEC-PRIC01" }`

**Reduced motion:** static Seat plate, all rows visible, no pin, no wheel capture.

**Pin-until-complete:** required. Virtual progress. No tall multi-vh sticky track.

- Contrast on paper ≥ 4.5:1
- Keyboard: arrows, PageUp/Down, Space advance the board; index and rail are buttons
- Semantic `<section>`, `<h2>`, `<dl>`, rail `role="tablist"`
- `aria-live="polite"` on the display plate

- Grain is a CSS overlay SVG, not a canvas
