# Sections area (sidecar)

The future ClickMotion **Sections** aisle: mid-page slices that sit under existing heroes. Motion-first. Prompt-sold. Pairable.

This is not a blocks/atoms gallery. Buttons and inputs belong in `sidecar/components/` later. Three.js playgrounds belong in `sidecar/elements/` later.

## Files

| File | Role |
|------|------|
| `LAW.md` | Locked decisions. Read first. |
| `CATALOG.md` | V1 kinds, languages, pairing, gold references |
| `quality-gate.md` | Authority test before a SKU is considered real |
| `template.mdx` | Sold-prompt skeleton (not yet copied to `content/prompts/`) |
| `kinds.json` | Section kind ids (sidecar source until taxonomy merge) |
| `pairing.md` | Which heroes each kind should sit under |
| `VISUAL_PASS.md` | **Mandatory** Chrome loop after every section build |
| `libraries/` | Motion, design languages, tokens, composition rules |
