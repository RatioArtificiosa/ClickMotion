**Product unit (their version of “SKU”):**

1. Markdown shell with Category / Type / License meta  
2. One or more **embedded video previews** of the finished build  
3. A single fenced ```text``` block: the **copy-paste AI prompt**  
4. No source component code in the free repo — **prompt + proof video only**

That validates MS’s model: **product = prompt + assets + recorded proof**, not an interactive sandbox.

## 3. Prompt anatomy (what they actually write)

### 3.1 Document skeleton (100% consistent)

```text
# {Name}
> Category / Type / License
## Video Preview  →  ![](../assets/videos/{Name}_N.mp4)  (0–6 clips)
## Prompt         →  ```text … implementation spec … ```
*Generated by MotionSites Export Tool*
```

### 3.2 Prompt body = implementation spec, not mood board

Winning prompts are **build recipes**:

- Stack + package versions (sometimes exact: `motion ^12.23.24`, `hls.js`, Lucide)  
- Fonts (Google Fonts URL or `@fontsource/*`)  
- Color tokens (hex and/or HSL CSS variables)  
- Section-by-section layout with **literal Tailwind class strings**  
- Exact copy (headlines, CTAs, nav labels)  
- Exact **video URLs** (CloudFront MP4 or Mux `.m3u8`)  
- Animation numbers: delay 0.2s, y: 20, duration 0.6, ease curves  
- Reusable CSS recipes (especially liquid glass)  
- Asset list when images are required (`logo.png`, dashboard shot, avatar)

### 3.3 Length distribution

| Band | Approx chars (prompt body) | Role |
| --- | --- | --- |
| Thin | ~1.5–2.5K | Single hero, fewer tokens, more “fill in” risk |
| Typical | ~3–5K | Full hero + nav + CTA + one motion system |
| Dense | ~7–11K | Multi-section landing (Liquid Glass, Investor Deck, NeoVision, Orbis) |

Corpus average ~**4K** characters. Quality tracks length: densest prompts encode full design systems.

### 3.4 Repeated internal recipes (copy-paste DNA)

**Liquid glass** appears in ~15–20 prompts with the **same CSS**:

```css
.liquid-glass {
  background: rgba(255, 255, 255, 0.01);
  background-blend-mode: luminosity;
  backdrop-filter: blur(4px);
  box-shadow: inset 0 1px 1px rgba(255, 255, 255, 0.1);
}
/* ::before = vertical white gradient border via mask-composite exclude, padding 1.4px */
.liquid-glass-strong { /* blur(50px), stronger inset + gradient opacities */ }
```

**Video hero defaults** (majority of catalog):

- `autoPlay` + `muted` + `loop` + `playsInline`  
- `object-cover` (sometimes `scale-150`, object-position tricks)  
- Top/bottom black gradient fades (often 200–320px)  
- Full viewport `min-h-screen` / `h-screen`

**Typography pairing (house style):**

| Font | Frequency (approx) | Role |
| --- | --- | --- |
| Inter | ~47 | Default UI / body |
| Instrument Serif | ~23 | Italic accent words, display |
| Geist | ~7 | SaaS UI |
| Barlow | ~6 | Body with Instrument Serif (agency set) |
| Space Grotesk / Manrope / Poppins | rare | Specialty |

**Instrument Serif italic on one keyword** (“AI Magic”, “Overview”, “Transform”) is a Motionsites signature.

**Motion vocabulary:**

| Pattern | Where it shows |
| --- | --- |
| Stagger fade/slide up (`opacity` + `y`) | Most Framer heroes |
| CSS keyframe marquee `translateX(0→-50%)` 20s linear | Social proof / banners |
| Scroll word-reveal (`useScroll` + per-word opacity) | AI Designer Agency, Neuralyn |
| Parallax dashboard / content (`useTransform` y) | Neuralyn, showcase bands |
| BlurText word-by-word | Liquid Glass Agency |
| Manual video loop fade via rAF | Aethera Studio |
| Loader counter 000→100 + rotating words | Loader Animation |
| Spline full-bleed 3D | Automation Machines only |
| GSAP / ScrollTrigger | Portfolio Cosmic, Dark Portfolio only |

**Mouse-follow / magnetic cursor:** effectively **absent** from free prompts. Interaction mode variety is weak outside scroll + entrance + marquee + one Spline.

## 4. Stack formula they optimize for

README claims: **React, Tailwind, Framer Motion, HLS.js**. Corpus confirms:

| Signal | Files mentioning (approx) |
| --- | --- |
| React | 51+ |
| Tailwind | 47+ |
| TypeScript | ~24 explicit |
| Lucide | ~31 |
| Framer / `motion` / `motion/react` | ~22–33 |
| Vite | ~19 (preferred scaffold) |
| Next.js | ~2 (Loader, rare) |
| hls.js | ~12–13 |
| shadcn/ui | ~11 |
| GSAP | 2 |
| Spline (`@splinetool/react-spline`) | 1 |
| Three.js / R3F | 0 true Three apps (word “three” hits false positives) |

**Scaffold preference:** Vite + React + TS + Tailwind, not Next App Router.  
**Icons:** Lucide almost exclusively.  
**CDN policy:** production hotlinks to **their** CloudFront and Mux. MS also uses CDN, but for **MS-owned** objects (gallery + buyer downloads). Ban is “someone else’s bucket as source of truth,” not “no CDN.”

| `prod.spline.design/….splinecode` | 3D scene | Automation Machines |

Buyer success depends on **their** CDN staying up. No self-contained asset zip in the free repo for those URLs.

### 5.2 Preview MP4s in `assets/videos/`

- Named `{PromptName}_{index}.mp4`  
- Screen recordings of the live site (proof, not raw stock)  
- Multi-clip previews for complex products (Liquid Glass 4, Orbis 6, Investor Deck 5)  
- One broken stub: `AI_Automation_Hero_0.mp4` (~1.4 KB)  
- Largest proofs ~20–29 MB (Aethera, Datacore Booking, Wealth, Sync AI, Terra)

### 5.3 Images folder is not a full asset library

Only a handful of GIFs/PNGs (AI Designer Agency GIFs are multi-MB loops).  
Most “assets needed” are **declared in prompt text** but not shipped as files next to the prompt.

## 7. Strengths vs gaps (for MS)

### What they do well (steal as standards, not brands)

1. **Proof video is the storefront** — multi-angle recordings for complex pages.  
2. **Prompts are executable specs** — classes, tokens, delays, URLs.  
3. **Reusable CSS product IP** — liquid glass recipe is consistent across SKUs (steal density, not as MS default chrome).  
4. **Export format is uniform** — meta + preview + prompt (easy to browse).  
5. **Taxonomy maps buyer intent** — SaaS / Agency / Portfolio / Hero.  
6. **House type pairing** creates catalog cohesion (Inter + Instrument Serif) — for them; MS must **not** clone this house look as our default.

### What looks “AI” in their free set (MS avoids as house style)

- Floating **pill / capsule navigation** rails  
- **Everything rounded-full** (nav + CTA + chips)  
- **Gradient mesh / aurora** as brand identity  
- Black + liquid glass + Instrument Serif on every other card  

MS storefront and sold prompts steer **famous human UI craft** (structured nav, intentional materials, named reference directions — Apple is one option, not a hardwire). Video craft and prompt density stay; capsule / gradient AI kits do not.

### Where MS can win

| Motionsites free set | MS standard |
| --- | --- |
| Hotlink **their** CloudFront + Mux (buyer depends on them) | **Own** the files; serve + sell downloads from **MS CDN** (cheap egress, not app origin) |
| Assets often missing from repo | **Prompt + asset pack** packaged; CDN URLs after entitlement |
| Interaction mostly entrance + scroll | Tag **video / 3D / scroll / mouse-follow** + capture each |
| Thin prompts still listed | **Quality floor** (complete design system or don’t ship) |
| Premium label but public files | Clear commercial packaging + CMS authority |
| No clean-room proof story | **Build-from-prompt** validation + visual QA loop |
| Vite+React only | Next/React; media still via MS CDN, not random hosts |
| Mentions of v0 / third-party builders in a few places | **Never v0**; CMS-first MS shell |
| Liquid glass everywhere in product | Liquid glass **only inside product prompts**, never MS chrome |
| Mute autoplay is common | **Always muted** previews (aligned) |
| Catalog volume (65) | Fewer, deeper SKUs with assets + proof beats thin volume |
| Samey black + glass + Instrument Serif + **pill nav / mesh gradients** | **Famous human UI references** (rotated); authority test; pill/gradient kits optional specials only |
| Interaction modes not productized | `technicalTags` + capture that proves the mode |

## 9. Prompt quality checklist derived from their best work

Use this when writing MS buyer prompts (and when scoring competitor clones):

- [ ] Stack + versions if non-default  
- [ ] Fonts with weights and assignment (display vs body)  
- [ ] Full color tokens (not “dark and premium”)  
- [ ] Every section numbered with layout + copy  
- [ ] Exact class strings for critical elements  
- [ ] Video: **MS path or MS CDN URL**, autoplay/muted/loop/playsInline, object-fit, overlays  
- [ ] Motion: library, property, duration, delay, easing, trigger (load vs scroll)  
- [ ] Reusable effects as named CSS/components (glass, BlurText, marquee)  
- [ ] Asset inventory (filenames the buyer must have; delivered from MS CDN)  
- [ ] Responsive breakpoints called out  
- [ ] No uncontrolled third-party media hosts (competitor CloudFront/Mux/etc.)

## 10. MS action items (from this dissect)

1. **Keep** video-first gallery (always-loop muted) — competitor already trains buyers this way.  
2. **Own + package** assets, then **serve/download from MS CDN** (origin stays thin; buyers pull media from CDN).  
3. **Encode** interaction modes in CMS `technicalTags` and in prompt sections (they don’t).  
4. **Adopt** density of Liquid Glass / Automation Machines prompts for V1 flagship SKUs; reject incomplete thin prompts.  
5. **Do not** ship MS shell with liquid glass; keep that recipe **inside** product prompts (already PRODUCT_LAW).  
6. **Multi-clip** product pages for multi-section landings (2–4 proof videos), matching their best gallery cards.  
7. **Instrument Serif + Inter + pill glass nav** is their house look — MS rotates real-world UI references and rejects AI-kit chrome.  
8. Track corpus offline: `_research/motionsites-prompts/` + `corpus_stats.csv` for regression comparisons.  
9. **Catalog variety + clean-room / visual QA + anti AI-slop (authority) UI** remain non-negotiable wins over their free set.
