## Concept brief (1A)

### One-line promise

**ORBIT FINANCE** is a full-viewport **trustworthy premium neobank hero**: deep navy vault stage, orbit gold signal, DM Serif lockup (**Money, elevated.**), a living wealth architecture film, and a signature gold orbital ring — free-play film, never scroll-scrubbed.

### Who + desire

- Neobanks, digital private banks, wealth apps, multi-currency / global banking startups  
- Want **trust and elevation**, not crypto hype or day-trader dopamine  
- Sell calm control of money before product features  

### Signature behavior (plain English)

1. Vault/wealth brand film free-plays muted full-bleed under soft navy scrims.  
2. Type + CTAs + proof stagger in (Framer).  
3. Signature **gold orbital ring** (thin geometric path, slow continuous rotate or draw) frames a void or sits as chrome — **UI only**, never burned into film.  
4. Optional soft metallic **card micro-float** (CSS/Framer) — synthetic product chrome, not film.  
5. Desktop only: soft film wrap scale parallax (`1 → ~1.05`), **never** `video.currentTime` scrub.  
6. Reduced motion: poster still + static ring + full type + no parallax.  

### Why someone pays

Buyers get a **Forbes-grade banking hero system** they can rebrand — film, orbital motif, serif lockup, proof, CTAs — without inventing private-bank craft from a cyan template.

**Kill forever from scaffold:** cyan primary HSL, pink secondary, pure black Motionsites kit.

### Typography

| Role | Face | Spec |
|------|------|------|
| Display / H1 | DM Serif Display | 400–500, tracking `-0.03em`, line-height ~0.95, `clamp(2.75rem, 7vw, 5.5rem)` |
| Wordmark | Inter | 12–13px bold, tracking `0.28em`, uppercase ORBIT |
| Body | Inter | 15–16px, cream ~72% |
| Proof value | DM Serif Display | ~1.35rem |
| Proof label | Inter | 9–10px uppercase tracking ~0.16em |
| CTA | Inter | 12–13px medium/semibold |

### Chrome law

- **Header:** minimal wordmark left · quiet links center (desktop) · Open account right gold pill  
- **Not** liquid-glass dock as the only identity  
- **Orbital ring:** absolute, pointer-events none, gold stroke ~1px, slow rotate 48–72s linear OR path draw once then idle — signature of ORBIT  
- **Scrims:** left/lower navy so serif type never sits on bright windows
