## Design System

**Aesthetic Direction:** Premium wellness brand **AETHER**. Biophilic full-viewport hero over golden-hour ocean waves. Cream wash, sage and warm gold accents, Playfair Display headlines, Inter body. Apple mindfulness x Aesop calm - never neon, never aviation, never fintech chrome.

**Famous-UI craft direction (not a clone):** Calm product marketing (Headspace / Calm class restraint) with editorial serif hierarchy. One soft video system only.

**Typography:**
- Display: Playfair Display 600 for `Breathe.` and `Be.`
- H1 `Breathe.`: dark sage `#2D3E35`, `clamp(2.8rem, 7.5vw, 6.75rem)`, line-height 1.05, tracking tight
- Subline `Be.`: sage `#7BA58F`, **0.58x H1** via `clamp(1.62rem, 4.35vw, 3.9rem)`, margin-top `-0.18em` - never larger than H1
- Body / nav: Inter 400-500, description 16-18px, muted `#5C6B63`, max-width ~36rem

**Colors:**
| Token | Hex |
|-------|-----|
| cream | `#FDFBF7` |
| dark sage | `#2D3E35` |
| sage | `#7BA58F` |
| warm gold | `#D4A373` |
| muted | `#5C6B63` |
| glass nav | `rgba(255,255,255,0.42)` + backdrop-blur |

**Radius:** pills on badge and CTAs (`rounded-full`).  
**Anti-slop:** no aurora mesh, no border-beam, no shiny gradient text, no purple SaaS kit stack.
